ER 図（jig-erd）

この図は「実装」です。 Flyway が実際に構築したスキーマから生成しています。 設計としての ER 図は データモデル設計 を参照してください。 両者を突き合わせることで、設計と実装の乖離を差分として検出できます。

Database per Service のため、図はサービスごとに分かれます。 サービスをまたぐ参照は論理参照であり、外部キーとしては存在しないため図には現れません。 1 枚の全体 ER 図にならないことが、設計上正しい姿です。

jig-erd が扱うのはテーブルと外部キーの関連のみです。 PK・データ型・制約の正典はデータモデル設計です。 なお flyway_schema_history は public スキーマにあるため図に現れます。
