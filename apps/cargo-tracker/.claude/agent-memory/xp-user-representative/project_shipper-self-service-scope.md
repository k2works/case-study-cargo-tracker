IT9（2026-08-09 クローズ）で US34 が入り、ROLE_SHIPPER に予約一覧・予約詳細（GET のみ）を開放した。IT2 で一度開放して取り消して以来 7 IT ぶり。

**Why:** 「あの貨物は今どうなっているか」の電話が毎日発生し営業の時間を奪っていた。紐付け手段（`users.shipper_id` / ADR-013）が無いことが唯一の障害だった。

**How to apply:**
- 荷主に開いてよいのは**自社の予約の照会**まで。登録・キャンセル・引き渡し・確定・通知送信は営業のもの（US34 の受入基準に明記）
- 絞り込みは必ず SQL 側。紐付けの無い荷主は「絞らない」ではなく**0 件に絞る**（設定漏れが漏洩に直結しない形）
- 他社の予約は 403 でなく 404（US18 の追跡照会と同じ判断）
- 荷主向け画面を足すときは、営業向け画面の使い回しに営業専用の操作ボタン・入口（例: 一覧の「新規予約登録」）が混ざっていないかを毎回見る
