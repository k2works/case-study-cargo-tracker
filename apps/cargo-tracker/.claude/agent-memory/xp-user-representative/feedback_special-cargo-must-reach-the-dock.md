危険物・冷凍など**取扱いを変える情報**は、登録できるようになった時点で「現場の担当者がどの画面で気づくか」まで確かめる。

**Why:** IT9 の US05 で危険物申告（クラス / UN 番号 / 正式輸送品名）と温度管理条件を登録・表示できるようにしたが、**荷役作業一覧・荷役作業登録の画面には貨物種別すら出ていない**。危険物は法的要件を伴い、冷凍は温度帯を外すと貨物そのものが失われる。記録しても現場に届かなければ US05 の「なぜなら（安全な輸送を保証）」は達成されない。

**How to apply:** 特殊な取扱い属性のレビューでは、登録画面・詳細画面に加えて、**その貨物に物理的に触る人の画面**（荷役、追跡、経路割り当て）に表示があるかを必ず確認する。バッジ 1 つでよい。
