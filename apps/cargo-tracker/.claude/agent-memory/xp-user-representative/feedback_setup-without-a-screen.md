「設定手段は画面に無い、運用手順で行う」と割り切った機能は、**その設定状態を業務側が確認できるか**を必ず聞く。

**Why:** ADR-013（利用者と荷主の紐付け）は設定画面を持たない判断をした。一方で予約一覧の空状態は荷主に「担当営業へお問い合わせください」と案内する。**問い合わせを受けた営業には紐付けの有無を見る画面が無い**ため、質問が答えられずに止まる。設定を省くこと自体は妥当でも、確認手段まで無いと業務が回らない。

**How to apply:** 「設定は運用で」と書かれた ADR を読んだら、(1) 誰が設定するのか、(2) 設定済みか未設定かを業務担当者が画面で見られるか、(3) 未設定時に利用者へ出す案内の宛先はその答えを持っているか、を確認する。読み取り専用の表示だけでも先に入れてもらう。
