「この操作は N 件に影響します」と件数を出したら、**その N 件へ行ける導線**と、**確定した後にその仕事が残っていると分かる手段**をセットで要求する。

**Why:** IT9 の航海更新確認画面は影響予約の件数を出し「荷主への連絡が必要か確認してください」と促すが、(1) 該当予約への導線が無い、(2) 案内先の「経路割り当て待ち」は**未割り当ての予約しか出ない**ので影響予約は現れない、(3) 更新後のフラッシュメッセージに件数が残らない。結果、確定ボタンを押した瞬間に「誰に連絡するのか」が失われる。

**How to apply:** 件数表示を見たら「この後この人は何をするのか」を必ず聞く。案内文で別画面を指すときは、その画面に本当に対象が現れるかを実装で確認する（一覧の抽出条件を読む）。
