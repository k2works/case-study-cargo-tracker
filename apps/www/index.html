稼働環境

ローカル統合環境（kind）で動いているアプリケーションです。 npx gulp k8s:open で転送を張っている間だけ開けます。

アプリケーション

React 19 + Vite。nginx が /api を API Gateway へ中継します。

ログインが要ります。動作確認用の利用者はログイン画面に並びます（ADR-0004） 開く

荷物の追跡（ログイン不要）

追跡番号だけで貨物の現在状況を照会できる唯一の公開経路です。

照会そのものは US18 で実装します 開く

ヘルスチェック

画面を配っている nginx の生死。API 側は npx gulp ops:health で見ます。

各サービスの健全性は運用要件定義の監視項目を参照 開く
