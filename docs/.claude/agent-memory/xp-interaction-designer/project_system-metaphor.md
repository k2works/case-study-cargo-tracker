ui_design.md は OOUX（オブジェクト指向 UI）を設計方針として採用。主要オブジェクト=貨物予約 / 追跡 / 荷役 / 航路 / 請求書。

**Why:** 一覧→詳細→アクションの流れを統一するため OOUX が明示されている。ただしシステム全体を貫く単一メタファーは未定義。

**How to apply:** メタファー提案時は「貨物のジャーニー（受付→経路設計→輸送→引取→精算）」を軸に、追跡タイムラインと予約ステータスを同じ旅程の可視化として統一する案が有力。
