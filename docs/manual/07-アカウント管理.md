# 07 アカウント管理

パスワードを続けて間違えて **ロックされたアカウント** を確認し、解除する画面です。
**システム管理者**が使います。

本章は [01 業務フロー](01-業務フロー.md#steps) の「ロックされたアカウントを解除する」に
あたります。

## 画面の開き方

メニューの **[アカウント管理]** を押します。URL は `/admin/accounts` です。

> **この画面はシステム管理者だけが開けます。** 他の担当者にはメニューに出ません。
> 誰でもロックを外せると、パスワードを守る仕組みそのものが意味を失うためです。

## なぜロックされるのか

パスワードを **5 回続けて間違える** と、そのアカウントは **15 分間** ロックされます。
知らないパスワードを機械的に試し続ける攻撃を防ぐためです。

> **ロックされた本人には理由が表示されません。** 「利用者 ID またはパスワードが正しく
> ありません」とだけ出ます。「その利用者 ID は存在する」と攻撃者に教えないためです。
> 本人から「入れない」と連絡を受けたら、この画面で確認してください。

> **15 分待てば自動で解除されます。** 急いで使いたいときにこの画面で解除します。

## 7.1 ロックされたアカウントを解除する {#unlock}

### この画面でできること

いまロックされているアカウントを一覧し、解除します。

### 画面の説明

| 列 | 説明 |
| :--- | :--- |
| 利用者 ID | ログインに使う ID |
| 氏名 | 画面に表示される呼び名 |
| 失敗回数 | 続けて間違えた回数 |
| ロック期限 | この時刻を過ぎると自動で解除されます（日本時間） |

> **パスワードは表示されません。** 解除の判断に要らないためです。

> **期限が切れたものは一覧に出ません。** 自動で解除されており、操作は要りません。

### 操作手順

1. 一覧で対象の利用者 ID を確かめます
2. その行の [解除する] を押します
3. 一覧から消えます。**その場でログインできるようになります**

> **失敗回数も 0 に戻ります。** 期限だけを消すと、次に 1 回間違えただけでまたロックされます。

> **すでに期限が切れていても、押して問題ありません。** エラーにはなりません。

### 記録されること

解除の操作は、**誰が・いつ・どのアカウントを** 解除したかが記録に残ります。
あとから「なぜこのアカウントが解除されているのか」を確認できます。

## この画面で出るメッセージ

| メッセージ | いつ出るか | どうすればよいか |
| :--- | :--- | :--- |
| この操作を行う権限がありません | システム管理者以外が開こうとした | 管理者に依頼してください |
| 指定されたアカウントが見つかりません | 利用者 ID が誤っている | 一覧から選び直してください |
