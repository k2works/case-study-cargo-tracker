# 付録 B トラブルシューティング

症状から引ける Q&A です。画面に出たメッセージがあれば、そのまま本ページ内を検索してください。

## Q1. ログインに関する症状

### Q1-1. ログインできない（「利用者 ID またはパスワードが正しくありません」）

| 確認すること | 対処 |
| :--- | :--- |
| 利用者 ID の綴りは正しいか | 管理者から通知された ID をそのまま入力します |
| キーボードの入力モードは半角か | 全角で入力すると一致しません |
| Caps Lock が有効になっていないか | パスワードは大文字と小文字を区別します |
| 5 回以上続けて失敗していないか | アカウントがロックされています。[Q1-2](#q1-2-正しいパスワードなのにログインできない) を参照してください |

**このメッセージは、ID が存在しない場合・パスワードが違う場合・ロックされている場合のすべてで同じです。仕様であり、不具合ではありません。** 区別して表示すると、その ID が実在することを第三者に教えることになります。

### Q1-2. 正しいパスワードなのにログインできない

アカウントがロックされている可能性があります。**パスワードを続けて 5 回間違えると 30 分間ロックされます。**

| 確認すること | 対処 |
| :--- | :--- |
| 直前に何度か入力を間違えたか | 30 分待ってから、正しいパスワードでログインします |
| 30 分待ってもログインできない | パスワードそのものが違う可能性があります。管理者に確認してください |
| 急いでいて待てない | **解除の手段は現在ありません。** 30 分お待ちください |

ロックの解除を待つ間に何度試しても、ロック時間は**延びません**。

> **管理者による即時解除の機能は、現在ありません。** 提供されるまでは 30 分お待ちいただく運用になります。

### Q1-3. 覚えのないログイン失敗でロックされる

第三者が ID を使ってログインを試みている可能性があります。**管理者に連絡してください。**

### Q1-4. アカウントを無効にされたと言われた

無効にされたアカウントは、パスワードが正しくてもログインできません。表示されるメッセージは Q1-1 と同じです。管理者に確認してください。

## Q2. 画面・メニューに関する症状

### Q2-1. あるはずのメニューが表示されない

**利用できる画面はロールによって変わります。** ロールに該当しない項目は、メニューそのものに表示されません。仕様であり、不具合ではありません。

| 確認すること | 対処 |
| :--- | :--- |
| 自分のロールは何か | [00. はじめに](00-はじめに.md#利用者-id-とロール) の表で確認します |
| 担当が変わったのにロールが古い | 管理者にロールの変更を依頼します |

### Q2-2. 画面を開こうとしたら「アクセスが拒否されました」と表示される

そのロールでは利用できない画面です。URL を直接入力した場合にも起こります。画面の「ダッシュボードに戻る」から作業を始めてください。

担当が変わってこの画面が必要になった場合は、[システム管理担当窓口](00-はじめに.md#システム管理担当窓口)にロールの変更を依頼してください。

### Q2-3. ログアウト後にブラウザの「戻る」で業務画面を見ようとしたが表示されない

**仕様です。** 共有端末で前の利用者の情報が見えないようにしています。

## Q3. 荷主登録に関する症状

### Q3-1. 「このメールアドレスは既に登録されています」と表示される

同じメールアドレスの荷主がすでに登録されています。**登録は行われていません。**

| 確認すること | 対処 |
| :--- | :--- |
| 提示された既存荷主が同じ取引先か | その荷主をそのまま使います。リンクから詳細を確認できます |
| 別の取引先か | 別のメールアドレスで登録し直します |

**どちらを使うかは担当者が判断します。** システムが自動でどちらかに寄せることはありません。

### Q3-2. 「登録」をクリックしても登録されず、項目が赤枠になる

必須項目が未入力か、形式が正しくありません。赤枠の項目の下に理由が表示されます。入力済みの内容は消えていないため、該当項目だけ直して再度「登録」をクリックしてください。

| 項目 | よくある原因 |
| :--- | :--- |
| メールアドレス | `@` を含まない形式になっている |
| 国 | 2 文字の国コードではない（日本は `JP`） |
| 郵便番号・都道府県・市区町村 | 未入力（**番地・建物名以外は必須です**） |

### Q3-3. 「法人」を選べない

法人荷主は今後の提供で対応します。現在は「個人」のみ登録できます。

### Q3-4. 登録した内容を直したい

登録内容の変更は今後の提供で対応します。管理者に連絡してください。

### Q3-5. 荷主一覧に「荷主が登録されていません」と表示される

まだ 1 件も登録されていない状態です。**エラーではありません。**「+ 新規荷主登録」から登録してください。

## Q4. 予約の確定でつまずいたとき

### Q4-1. 「経路が割り当てられていない予約は確定できません」と表示される

まだ経路が決まっていません。運ぶ道筋が決まっていない予約は確定できません。経路担当者が経路を割り当てるのを待ってください（[5.4](05-航路管理.md#54-経路候補を算出して確定する)）。

### Q4-2. 「満船の便が含まれています（V0001）。経路を選び直してください」と表示される

経路候補を算出したあとに、別の貨物がその便を埋めました。**確定の瞬間に空きを数え直しているため、ここで止まります。** 経路担当者に別の便での割り当てを依頼してください。

### Q4-3. 「この状態の予約は確定できません」と表示される

すでに確定済みか、キャンセル済みです。予約詳細のステータスを確認してください。

### Q4-4. 「予約を確定」ボタンが表示されない

経路が割り当てられていないか、すでに確定済みです。**押せないボタンは表示しない方針**のため、ボタンが無いことがそのまま「今はできない」という意味です。

## Q5. 追跡番号でつまずいたとき

### Q5-1. 「確定していない予約には追跡番号を発行できません」と表示される

営業担当者が予約を確定するのを待ってください。確定された予約は「追跡管理」の一覧に現れます（[7.1](07-追跡管理.md#71-発行待ちの予約を確認する)）。

### Q5-2. 「この予約にはすでに追跡番号 TRK-… が発行されています」と表示される

発行済みです。**表示された番号をそのまま荷主に連絡してください。** 番号は予約詳細でいつでも確認できます。

### Q5-3. 発行した追跡番号が分からなくなった

予約詳細の「追跡番号」欄で確認できます。予約が分からない場合は、荷主名・出発地・目的地から貨物予約一覧で探してください。

## Q6. 荷役の登録でつまずいたとき

### Q6-1. 「追跡番号の形式が正しくありません」と表示される

`TRK-20260401-0001` の形式で入力してください。このメッセージは**入力欄のすぐ下**に出ます。

### Q6-2. 「追跡番号 TRK-… の貨物が見つかりません」と表示される

番号の写し間違いか、追跡番号がまだ発行されていません。**このメッセージはフォームの上**に出ます。番号を確認しても見つからない場合は追跡担当者に問い合わせてください。

### Q6-3. 「積込 には航海番号が必要です」と表示される

積込・荷降しは、どの便に対する作業かが必要です。貨物の予定ルートの航海番号を入力してください。

### Q6-4. 「予定ルートに無い積込です」と警告が出た

**登録は済んでいます。** ただし予定と違う便・港に積み込まれており、誤配として記録されました。**追跡担当者に連絡してください。**

### Q6-5. 「他の操作が先に行われました」と表示される

他の担当者が同時に同じ貨物を操作しました。**このとき作業は記録されていません。** 一覧で状態を確かめてから登録し直してください。

### Q6-6. 登録した作業を間違えた

荷役記録の訂正・取り消しは今後の提供で対応します。追跡担当者に連絡してください。
