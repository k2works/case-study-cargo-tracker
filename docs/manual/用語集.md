# 付録 A 用語集

本マニュアルと画面に登場する言葉の説明です。

## 1. 業務用語

| 用語 | 説明 |
| :--- | :--- |
| 荷主 | 貨物の輸送を依頼する取引先です。個人と法人があります |
| 荷主コード | 荷主を識別する番号です。登録時にシステムが発行します（例: SHP-000001）。利用者は指定できません |
| 個人荷主 | 個人として輸送を依頼する荷主です。契約による割引はありません |
| 法人荷主 | 法人として輸送を依頼する荷主です。契約番号と契約割引率を持ちます |
| 契約番号 | 法人契約の番号です。精算時に割引の根拠として請求書に記載されます |
| 契約割引率 | 法人荷主に適用される割引の割合です。0.00 〜 30.00% の範囲で設定します。**個人荷主には契約割引という考え方そのものがありません**（一覧では `-` と表示されます） |
| 荷受人 | 貨物を受け取る方です。引取のときの本人確認に使います。**予約の時点では未確定でもかまいません** |
| 貨物 | 輸送する荷物です |
| 予約 | 貨物の輸送を申し込む手続きです |
| 経路 | 出発地から到着地までの輸送の道筋です |
| 荷役 | 貨物の積み込み・荷降ろしなどの作業です |
| 引取 | 目的港で荷受人へ貨物を引き渡す作業です。記録すると予約が「配送完了」になります |
| 確認コード | 荷受人へ事前に送付する番号です。引取のときに照合し、引き渡しの証明として記録します |
| 誤配 | 予定と違う便・港に積み込む、または荷降ろすことです。記録は残り、貨物の経路状態が「誤配」になります。**受領・引取の場所の違いは誤配とは呼びません**（輸送そのものは予定どおり進むため） |
| 追跡 | 貨物が今どこにあるかを確認することです |
| 追跡番号 | 貨物を識別する番号です（例: `TRK-20260401-0001`）。予約の確定後に発行され、**荷主が輸送状況を問い合わせるときの唯一の手がかり**です |
| 公開追跡 | ログインせずに追跡番号だけで状況を照会できる画面です。URL をそのまま取引先へ共有できます |
| 手動更新 | 出港・入港のように**荷役作業として記録されない状態変化**を、追跡担当者が手で入れることです。履歴には「手動」と記録者が残ります |
| 出港 / 入港 | 船が港を出た・港に着いたことです。**荷役作業ではありません**。入港では貨物の状態は変わりません（変わるのは荷降ろしのときです） |
| 引取待ち | 荷降ろしが済み、荷受人の引き取りを待っている状態です |
| 探索条件 | 経路候補を算出するときに使う条件です。希望到着期限と経由回数の上限があります |
| 再算出 | 条件を緩めて経路候補を出し直すことです。候補ゼロは日常的に起きるため、期限や経由回数を緩めて探し直します |
| 経由回数 | 目的地に着くまでに寄る港の数です。上限は探索条件で指定します |
| 通知履歴 | 荷主へ経路を通知した記録です。送信日時・送信先・送信者・結果が残ります。**「送ったつもり」を後から確かめるためのものです** |
| 精算 | 輸送の代金を請求し、入金を確認することです |
| 危険物申告 | 危険物を輸送するときに要る申告です。**危険物クラス・UN 番号・正式輸送品名**の 3 つで 1 組です。輸送書類にそのまま載ります |
| 危険物クラス | 国連分類による危険性の区分です（例: `3` は引火性液体） |
| UN 番号 | 国連が定める危険物の番号です（例: `UN1263`） |
| 正式輸送品名 | 危険物の**英語の正式名称**です。商品名ではありません |
| 温度管理条件 | 冷凍・冷蔵貨物を保つ温度帯です。**最低温度・最高温度・単位**の 3 つで 1 組です |
| 運航変更 | 運送会社が発表するスケジュールの変更です。登録済みの航海スケジュールを更新して反映します |
| 差分（変更内容） | 更新の前後で**変わった項目だけ**を並べたものです。確定する前に確認します |

## 2. 画面用語

| 用語 | 説明 |
| :--- | :--- |
| ダッシュボード | ログイン後に表示される入口の画面です。ロール別の作業カードが並びます |
| ロール | 利用者の役割です。ロールによって表示される画面が変わります |
| 利用者 ID | ログインに使う ID です。[システム管理担当窓口](00-はじめに.md#システム管理担当窓口)から通知されます |
| 管理者 | [システム管理担当窓口](00-はじめに.md#システム管理担当窓口)のことです。利用者 ID の発行・ロールの変更・登録内容の訂正を依頼できます |
| アカウントロック | パスワードを続けて間違えたときに、一定時間ログインできなくなる状態です |
| 必須項目 | 入力しないと登録できない項目です。画面では項目名の後ろに赤い `*` が付きます |
| 空状態 | データが 1 件も無いときの表示です。エラーではありません |
| 荷主の紐付け | 荷主アカウントとその会社（荷主）を結びつける設定です。**この設定があるアカウントだけが自社の予約を見られます** |

## 3. 住所の項目

| 用語 | 説明 |
| :--- | :--- |
| 国 | 2 文字の国コードです。日本は `JP` です |
| 郵便番号 | 郵便番号です |
| 都道府県 | 都道府県（国によっては州・省）です |
| 市区町村 | 市区町村です |
| 番地・建物名 | 番地や建物名です。唯一の任意項目です |
