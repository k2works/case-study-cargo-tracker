# 付録 A 用語集

本マニュアルと画面に登場する言葉の説明です。

## 1. 業務用語

| 用語 | 説明 |
| :--- | :--- |
| 荷主 | 貨物の輸送を依頼する取引先です。個人と法人があります |
| 荷主コード | 荷主を識別する番号です。登録時にシステムが発行します（例: SHP-000001）。利用者は指定できません |
| 個人荷主 | 個人として輸送を依頼する荷主です。契約による割引はありません |
| 法人荷主 | 法人として輸送を依頼する荷主です。契約番号と契約割引率を持ちます |
| 契約番号 | 法人契約の番号です。精算時に割引の根拠として請求書に記載されます |
| 契約割引率 | 法人荷主に適用される割引の割合です。0.00 〜 30.00% の範囲で設定します。**個人荷主には契約割引という考え方そのものがありません**（一覧では `-` と表示されます） |
| 荷受人 | 貨物を受け取る方です。引取のときの本人確認に使います。**予約の時点では未確定でもかまいません** |
| 貨物 | 輸送する荷物です |
| 予約 | 貨物の輸送を申し込む手続きです |
| 経路 | 出発地から到着地までの輸送の道筋です |
| 荷役 | 貨物の積み込み・荷降ろしなどの作業です |
| 引取 | 目的港で荷受人へ貨物を引き渡す作業です。記録すると予約が「配送完了」になります |
| 引取確認コード | 予約の確定時にシステムが採番する番号です（`CLM-` に続く 8 文字。数字と英大文字）。営業担当者が荷主へ伝え、引取のときに**システムが照合します**。**追跡番号とは別の値です** — 追跡番号を知っているだけでは引き取れません |
| 訂正・取り消し申請 | 誤って登録した引取記録を直すための申請です。荷役作業員が申請し、**追跡管理者が承認して初めて**貨物の状態が戻ります |
| 誤配 | 予定と違う便・港に積み込む、または荷降ろすことです。**登録の前に確認画面が出て、承認して初めて記録されます。** 記録すると貨物の経路状態が「誤配」になり、追跡担当者に例外が起票されます。**受領・引取の場所の違いは誤配とは呼びません**（輸送そのものは予定どおり進むため） |
| 通関申告 | 輸入港で税関へ提出する申告の記録です。**1 つの貨物に 1 件**で、荷役種別「通関」の作業に紐づきます。状態は審査中・通関済・留置・不可の 4 つです |
| 通関済 | 税関の審査が通り、引き取りに進める状態です。**この状態でなければ引取は登録できません。** 通関済にすると以後その申告は変更できません |
| 留置 | 書類の不備や検査で税関に貨物が止められている状態です。**保管料が発生します。** 留置になると「税関保留」の例外が自動で起票され、3 日を超えると一覧とダッシュボードで警告されます |
| 超過日数 | 経路候補の到着予定が、**予約の希望期限**を何日超えるかです。条件を緩めて探した期限ではなく、当初の約束と比べます。荷主への通知本文にも入ります |
| 追跡 | 貨物が今どこにあるかを確認することです |
| 追跡番号 | 貨物を識別する番号です（例: `TRK-20260401-0001`）。予約の確定後に発行され、**荷主が輸送状況を問い合わせるときの唯一の手がかり**です |
| 公開追跡 | ログインせずに追跡番号だけで状況を照会できる画面です。URL をそのまま取引先へ共有できます |
| 手動更新 | 出港・入港のように**荷役作業として記録されない状態変化**を、追跡担当者が手で入れることです。履歴には「手動」と記録者が残ります |
| 出港 / 入港 | 船が港を出た・港に着いたことです。**荷役作業ではありません**。入港では貨物の状態は変わりません（変わるのは荷降ろしのときです） |
| 引取待ち | 荷降ろしが済み、荷受人の引き取りを待っている状態です |
| 探索条件 | 経路候補を算出するときに使う条件です。希望到着期限と経由回数の上限があります |
| 再算出 | 条件を緩めて経路候補を出し直すことです。候補ゼロは日常的に起きるため、期限や経由回数を緩めて探し直します |
| 経由回数 | 目的地に着くまでに寄る港の数です。上限は探索条件で指定します |
| 通知履歴 | 荷主へ経路を通知した記録です。送信日時・送信先・送信者・結果が残ります。**「送ったつもり」を後から確かめるためのものです** |
| 精算 | 輸送の代金を請求し、入金を確認することです |
| 輸送料金 | 引取が済んだ貨物に対して算出する代金です。基本料金・割引・消費税から求めます（[11.2](11-請求管理.md#112-料金を算出する)） |
| 基本料金 | 距離係数 × 重量 × 貨物種別係数で求める、割引を適用する前の料金です。**経路候補の「費用（概算）」とは別の計算です** |
| 料金の状態 | 「下書き」（確認中）と「確定」（承認済み）の 2 つです。**支払いの状態とは別の軸です** — 「料金は確定したが未入金」と「料金が未確定」は違います |
| 料金調整 | 例外（遅延・破損等）が起きた貨物に対して入力する、減額と補償費用です。**理由が必須です**。**割引は調整した後の額に掛かります** |
| 請求書（発行） | 確定した輸送料金をもとに発行する書面です。**請求番号・請求金額・支払期限**を持ちます（[11.5](11-請求管理.md#115-請求書を発行する)）。**設計上の呼び名は「精算書」ですが、画面とマニュアルでは「請求書」に統一しています** |
| 支払期限 | 請求書を発行した日から既定で 30 日後です（運用の設定で変わります）。**発行した時点で決まり、後から動きません**。**期限当日は超過ではありません** |
| 支払いの状態 | 「未入金」「入金確認済」「支払期限超過」の 3 つです。**料金の状態とは別の軸です**。発行していない請求書は支払いの状態を持ちません |
| 支払期限超過 | 支払期限の翌日以降で、まだ入金が確認できていない状態です。督促の対象です（[11.7](11-請求管理.md#117-支払期限超過を確認する)） |
| 入金の確認 | 荷主からの入金を記録する操作です。**請求額どおりの金額だけを記録できます**。確認すると予約が「精算完了」になります |
| 精算完了 | 入金まで終わった予約の状態です。**この状態になると引取記録の訂正・取り消しはできません** |
| 危険物申告 | 危険物を輸送するときに要る申告です。**危険物クラス・UN 番号・正式輸送品名**の 3 つで 1 組です。輸送書類にそのまま載ります |
| 危険物クラス | 国連分類による危険性の区分です（例: `3` は引火性液体） |
| UN 番号 | 国連が定める危険物の番号です（例: `UN1263`） |
| 正式輸送品名 | 危険物の**英語の正式名称**です。商品名ではありません |
| 温度管理条件 | 冷凍・冷蔵貨物を保つ温度帯です。**最低温度・最高温度・単位**の 3 つで 1 組です |
| 運航変更 | 運送会社が発表するスケジュールの変更です。登録済みの航海スケジュールを更新して反映します |
| 差分（変更内容） | 更新の前後で**変わった項目だけ**を並べたものです。確定する前に確認します |
| 例外 | 輸送が計画どおりに進まなくなった出来事です。**遅延・破損・紛失**を記録します。国際輸送では珍しいことではありません |
| 遅延 | 到着が予定より遅れることです。管理者へのエスカレーションはしません |
| 破損 | 貨物が傷んだことです。**解決しても破損の事実は残ります**（料金の調整の根拠になります） |
| 紛失 | 貨物の所在が分からなくなったことです。**必ずエスカレーションされます** |
| エスカレーション | 現場の権限を超える判断（保険手続き・補償対応）を管理者に上げることです。**メールや電話では届きません。** 管理者はダッシュボードのカードで気づきます |
| 例外の解決（対応） | 例外への対応が済んだことを記録することです。「無かったこと」にする操作ではありません |
| 発生前の状態 | 例外が起きる直前の輸送状態です。対応を記録すると、貨物はこの状態に戻ります |

## 2. 画面用語

| 用語 | 説明 |
| :--- | :--- |
| ダッシュボード | ログイン後に表示される入口の画面です。ロール別の作業カードが並びます |
| ロール | 利用者の役割です。ロールによって表示される画面が変わります |
| 利用者 ID | ログインに使う ID です。[システム管理担当窓口](00-はじめに.md#システム管理担当窓口)から通知されます |
| 管理者 | [システム管理担当窓口](00-はじめに.md#システム管理担当窓口)のことです。利用者 ID の発行・ロールの変更・登録内容の訂正を依頼できます |
| アカウントロック | パスワードを続けて間違えたときに、一定時間ログインできなくなる状態です |
| 必須項目 | 入力しないと登録できない項目です。画面では項目名の後ろに赤い `*` が付きます |
| 空状態 | データが 1 件も無いときの表示です。エラーではありません |
| 荷主の紐付け | 荷主アカウントとその会社（荷主）を結びつける設定です。**この設定があるアカウントだけが自社の予約を見られます** |

## 3. 住所の項目

| 用語 | 説明 |
| :--- | :--- |
| 国 | 2 文字の国コードです。日本は `JP` です |
| 郵便番号 | 郵便番号です |
| 都道府県 | 都道府県（国によっては州・省）です |
| 市区町村 | 市区町村です |
| 番地・建物名 | 番地や建物名です。唯一の任意項目です |
