## 執筆テンプレート

各章は次の順で書きます。読者は「何をしたいか」から入るので、機能の説明ではなく操作から始めます。

1. **この章でできること** — 1〜2 行
2. **手順** — 番号つき。1 手順 1 操作。画面キャプチャは手順の直後に置く
3. **うまくいかないとき** — 実際に出るメッセージをそのまま見出しにする
4. **関連する章**

## キャプチャの方針

- 画面キャプチャは **Playwright が自動生成**します（`npx gulp manual:capture`）。手で配置しません
- 出力先は `docs/manual/assets/`。ファイル名は `<章番号>-<画面 ID>.png`
- 画面を変えたらキャプチャを撮り直します。**古いキャプチャは、書いていないことよりも読者を迷わせます**
- キャプチャに写す値は固定の見本データにします。日付や採番が毎回変わると、差分が本当の変化かどうか分かりません

## 表記の約束

| 対象 | 書き方 | 例 |
| :--- | :--- | :--- |
| ボタン・リンク | `[ ]` で囲む | `[登録する]` を押します |
| 入力欄 | 「 」で囲む | 「メールアドレス」に入力します |
| 画面名 | そのまま | 荷主一覧 |
| メッセージ | 実際の文言をそのまま | 「このメールアドレスは既に登録されています」 |
