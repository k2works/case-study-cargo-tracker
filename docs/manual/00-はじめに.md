# 00. はじめに

## このマニュアルの読み方

業務の流れから探すときは [01. 業務フロー](01-業務フロー.md) を、画面から探すときは下の全体構成表を使ってください。操作中に困ったときは [付録 B トラブルシューティング](付録B-トラブルシューティング.md) を症状から引けます。

| 章 | 内容 | 主な利用者 |
| :--- | :--- | :--- |
| [01. 業務フロー](01-業務フロー.md) | 業務の流れと各章への入口 | 全員 |

| [付録 B トラブルシューティング](付録B-トラブルシューティング.md) | 症状から引く Q&A | 全員 |

## 表記規約

| 規約 | 例 |
| :--- | :--- |
| 文体はですます調 | 「〜します」「〜してください」 |
| ボタン・タブ・入力項目・選択肢は「」で囲む | 「登録」をクリックします |
| 画面の場所はメニュー → 画面の順 | メニュー「荷主管理」→「新規荷主登録」 |
| 画面項目には丸数字を振り、表で対応させる | ①②③… |
| 状態は画面の表示名で書く | 「個人」「法人」 |
| 専門用語は初出で簡潔に補足し用語集へリンク | [用語集](用語集.md) |

## 利用者 ID とロール

利用できる画面は**ロール**（役割）によって変わります。ロールに該当しない項目は、画面のメニューそのものに表示されません。「あるはずのメニューが見えない」ときは、まず自分のロールを確認してください。

| ロール | 主な担当業務 | 本マニュアルで利用できる画面 |
| :--- | :--- | :--- |
| 営業担当者 | 荷主の登録、貨物の予約 | ダッシュボード、荷主管理 |
| 経路担当者 | 経路の設計と割り当て | ダッシュボード |
| 追跡担当者 | 貨物の追跡と例外対応 | ダッシュボード |
| 荷役担当者 | 荷役作業の登録 | ダッシュボード |
| 精算担当者 | 請求と入金 | ダッシュボード |

> 経路・追跡・荷役・精算の画面は、機能の提供にあわせて追加します。

## システム管理担当窓口

本マニュアルで「管理者」と書いている相手は、**システム管理担当窓口**です。次のことを依頼できます。

| 依頼できること | 例 |
| :--- | :--- |
| 利用者 ID の発行・パスワードの再設定 | 入社・異動・パスワードを忘れた |
| ロールの変更 | 担当業務が変わり、別の画面が必要になった |
| 登録内容の訂正 | 荷主の名称や住所を誤って登録した |

> **連絡先は運用開始時にここへ記載します。** 現在は社内の運用ルールに従ってください。

アカウントのロック解除は、現在この窓口でも行えません（[2.4](02-ログイン.md#24-アカウントがロックされたとき)）。

## 用語について

本マニュアルは画面に表示される言葉で書いています。データベースの項目名やシステム内部の名前は登場しません。意味が分からない言葉は [付録 A 用語集](用語集.md) を参照してください。
