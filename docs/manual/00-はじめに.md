# 00 はじめに

## このマニュアルについて

国際貨物輸送管理システムの操作を、業務の担当ごとに説明します。画面の見た目や文言は実際のシステムに合わせています。

## 動作環境

| 項目 | 内容 |
| :--- | :--- |
| ブラウザ | Google Chrome / Microsoft Edge の最新版 |
| 画面の大きさ | 幅 1280 ピクセル以上を推奨 |
| 日付・時刻 | 日本時間（Asia/Tokyo）で表示します |

## 担当と使える画面

ログインした利用者の担当（ロール）によって、左側のメニューに出る画面が変わります。**メニューに出ない画面は開けません。** 必要な画面が出ない場合は管理者に連絡してください。

| 担当 | 主に使う画面 |
| :--- | :--- |
| 営業担当者 | 荷主一覧、荷主登録、予約一覧、予約登録、要確認一覧 |
| 経路設計者 | 経路設計作業、航海スケジュール、航海登録、予約一覧 |
| 追跡管理者 | 予約一覧、要確認一覧 |
| 経理担当者 | 荷主一覧、要確認一覧 |
| システム管理者 | 利用者管理 |

まだ画面が用意されていない担当（荷役作業員・荷主）もあります。順次増えます。

## 覚えておくと迷わないこと

**登録した直後、一覧にすぐ出ないことがあります。** このシステムは登録を受け付けてから一覧に反映するまでに数秒かかります。画面には「登録を受け付けました。反映までしばらくお待ちください」と出ます。**失敗ではありません。** 一覧は自動で取り直すので、そのままお待ちください。

**しばらく操作しないとログアウトします。** 無操作が 15 分続くと画面下に警告が出て、20 分でログアウトします（荷役の画面をお使いの方は 60 分）。**入力中の内容は保存されません。** 詳しくは [02 ログインとログアウト](02-ログインとログアウト.md) を見てください。
