# 00 はじめに

## このマニュアルについて

国際貨物輸送管理システムを日々の業務で使うための手引きです。画面ごとに章を分け、「この画面でできること」「画面の開き方」「画面の説明」「操作手順」「注意・補足」の順に書いています。

困ったときは、まず該当画面の章の「注意・補足」を読んでください。

## 表記のきまり

| 表記 | 意味 |
| :--- | :--- |
| 「検索」 | 画面上のボタン・入力項目・選択肢の名前 |
| メニュー「荷主管理」 | 画面左側のメニュー項目 |
| ①②③ | 画面キャプチャ上の番号と、その下の表の項目が対応します |

## 動作環境

| 項目 | 内容 |
| :--- | :--- |
| ブラウザ | Google Chrome / Microsoft Edge の最新版 |
| 画面サイズ | 横 1280 ピクセル以上を推奨します |

## 担当と見える画面

このシステムでは、担当によって使える画面が変わります。自分の担当にない画面を開くと「この操作を行う権限がありません」と表示されます。担当の追加が必要な場合はシステム管理者に依頼してください。

| 担当 | 主に使う画面 |
| :--- | :--- |
| 営業担当者 | 荷主管理・見積管理・貨物予約 |
| 経路設計者 | 航海スケジュール・経路設計 |
| 荷役作業員 | 荷役管理・通関管理 |
| 追跡管理者 | 貨物状態管理・キャンセル承認・荷役管理・通関管理 |
| 経理担当者 | 精算管理 |
| 荷主 | 貨物予約（自分の予約の確認） |

> 現在のリリースで使えるのは、ログインと荷主管理です。他の画面は順次追加されます。

## 追跡番号をお持ちの方へ

貨物の追跡照会はログインなしで利用できます。トップページの追跡番号欄をお使いください（次のリリースで利用できるようになります）。
