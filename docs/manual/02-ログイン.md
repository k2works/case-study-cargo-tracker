## 2.1 ログインする

### この画面でできること

自分の担当に応じた画面を使えるようにします。ログインすると、担当ごとのダッシュボードが表示されます。

### 画面の開き方

トップページ →「業務利用の方はログイン」（URL: `/login`）

### 画面の説明

![ログイン画面](assets/02-login.png)

| # | 項目 | 説明 |
|---|------|------|
| ① | 「利用者 ID」 | 管理者から配布された ID を入力します |
| ② | 「パスワード」 | 入力した文字は伏せ字で表示されます |
| ③ | 「ログイン」 | 入力した内容でログインします |
| ④ | 「追跡照会はこちら」 | ログインせずに貨物を追跡する画面へ移動します |

### 操作手順

1. 「利用者 ID」に自分の ID を入力します
2. 「パスワード」を入力します
3. 「ログイン」をクリックします
4. 担当に応じたダッシュボードが表示されます

### 注意・補足

- ログイン後の画面は担当によって変わります。表示されるはずの項目が無い場合は、担当の設定を管理者に確認してください
- ブラウザのタブを閉じるとログイン状態は終わります。次に開くときは再度ログインが必要です

## 2.2 ログアウトする

### この画面でできること

作業を終えるとき、他の人が同じ端末を使う前に、自分の情報が見られないようにします。

### 画面の開き方

どの画面でも、右上に「ログアウト」があります。

### 画面の説明

![ダッシュボード](assets/02-dashboard.png)

| # | 項目 | 説明 |
|---|------|------|
| ① | 利用者名と担当 | 今ログインしている人と、その担当が表示されます |
| ② | 「ログアウト」 | ログイン画面に戻ります |
| ③ | メニュー | 自分の担当で使える画面が並びます |

### 操作手順

1. 画面右上の「ログアウト」をクリックします
2. ログイン画面に戻ります

### 注意・補足

- **共用の端末では、席を離れる前に必ずログアウトしてください**
- ログアウト後にブラウザの「戻る」を押しても、業務画面は表示されません

## 2.3 ログインできないとき

### よくある原因

| 症状 | 考えられる原因と対処 |
| :--- | :--- |
| 「利用者 ID またはパスワードが正しくありません」と表示される | 入力の誤り、または後述のアカウントロックです。まず入力内容（大文字小文字・全角半角）を確認してください |
| 何度試しても入れない | 連続して 5 回失敗すると、15 分間ログインできなくなります。15 分お待ちいただくと自動的に解除されます |
| 15 分待っても入れない | アカウントが無効化されている可能性があります。管理者にお問い合わせください |
| 「サーバーに接続できませんでした」と表示される | 認証の問題ではありません。ネットワークかシステム側の一時的な不調です。時間をおいて再度お試しください。続く場合は管理者にご連絡ください |

### 注意・補足

- **画面のメッセージは、原因が何であっても同じ文言です。** 「その ID は存在するか」を画面から読み取れないようにしているためです。ご自身の状況が分からない場合は管理者にお問い合わせください
- ロックされた場合、解除のための操作は不要です。15 分経過すると自動的に入れるようになります
- ログインの成否は記録されています。心当たりのない時間帯にログインの試みがあった場合は管理者にご相談ください

## 2.4 開発環境でのログイン

### この節の対象

開発環境（動作確認用の環境）だけの表示です。**実際の業務で使う環境には表示されません。**

### 画面の説明

![開発環境のログイン画面](assets/02-login-dev.png)

| # | 項目 | 説明 |
|---|------|------|
| ① | 「開発環境です」の表示 | この環境が動作確認用であることを示します |
| ② | 動作確認用の利用者 | 担当ごとの利用者 ID と、その担当で何ができるかが並びます |
| ③ | 利用者 ID のリンク | クリックすると下の入力欄に反映されます |
| ④ | 入力欄 | あらかじめ入力済みです。そのまま「ログイン」できます |

### 操作手順

1. 確かめたい担当の利用者 ID をクリックします
2. 「ログイン」をクリックします

パスワードは一覧の全員で共通のため、入力し直す必要はありません。

### 注意・補足

- **この表示が業務で使う環境に出ていたら、それは設定の誤りです。** システム管理者にご連絡ください
- 「無効化されたアカウント」は、ログインできないことを確かめるための利用者です。ログインを試みても入れません（[2.3](#23-ログインできないとき) の動作確認に使います）
