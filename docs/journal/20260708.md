## 学び

- **設計ドキュメントのドリフトは「実装が正・docs 追従」で解消するが、SoT（domain-model）が一時的に信頼できなくなる**。設計変更時は domain-model / data-model / iteration_plan / 実装を横断更新するチェックを validating-design に組み込むべき（Try T1）。
- **SQLite の型アフィニティは Dapper のマテリアライザキャッシュを壊す**。同一 NUMERIC 列が行ごとに Int64/Double を返し、先頭行の型でキャッシュされた materializer が後続行で失敗する。対策は「SQLite の decimal 列は TEXT アフィニティ」+「Guid/DateOnly は `[ModuleInitializer]` で TypeHandler 登録」。二方言差異は一箇所に封じ込める。
- **Npgsql は date 型パラメータに文字列を受けない**。DateOnly は深夜の DateTime + DbType.Date で渡し、読み取りは DateTime.Parse で頑健化する。
- **htmx を非入力要素（div）に付けると GET にトリガ値が乗らない**。ラジオ/セレクトの値を送るには `hx-include`（div の場合）またはトリガ要素自身に hx 属性を付ける。
- **E2E の `button[type=submit]` は DOM 先頭の別ボタンを踏む**。認証済みページは navbar のログアウトボタンが先頭にあり誤クリック → サインアウト。フォーム送信は文言セレクタ（`button:has-text('登録する')`）で特定する。サーバーの Debug ログ（Authentication/Antiforgery）が切り分けの決め手だった。
- **ArchUnit のルール 3（App→Infra 非依存）を「緑にする」過程が設計改善そのもの**。ポート（IUnitOfWork/IDbConnectionFactory）を Infrastructure 名前空間から Application へ移し、コマンドサービスを `IUnitOfWorkFactory` 経由にすることで DIP バイパス（M2）も同時に解消した。テストを先に置き、通すために設計を直す。
- **`ResideInNamespace(pattern, true)` は ArchUnitNET 0.13 に存在しない**。regex 版は `ResideInNamespaceMatching(pattern)`。
- **名前空間セグメントと型名の衝突（`CargoTracker.Shipper` vs 型 `Shipper`）は using エイリアスで回避**（`using ShipperAggregate = ...`）。Haskell の field 名衝突と同型の問題。
- **description 最適化はアンダートリガーを文言では直せない**。Opus 4.8 は簡単なタスクをスキル参照せず自力処理するため、should-trigger が 0 になる。文言最適化の限界を理解する。
