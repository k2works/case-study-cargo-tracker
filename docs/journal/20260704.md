## 学び

- **並列エージェントへの共通指示には「正が 1 つの値」（バージョン番号・製品名）を明示的に固定する**。マッピング表を渡しても、指示にない周辺値はエージェントごとに揺れる
- **サブエージェントのセッション上限は fan-out の途中でも起きる**。部分適用状態を検出する術は「エージェントの完了報告を信じず grep で残存を数える」こと。今回 `grep -c "EF Core"` の残存カウントが復旧の起点になった
- **トレーサビリティのドリフトは複数視点レビューで初めて確定する**。3 エージェントが同じズレを別ルート（画面・テスト・業務）から指摘したことで、「旧採番の残骸」という診断に確信が持てた
- **ORM を外すと「フレームワークが暗黙に解決していた問題」が全部設計課題として現れる**（集約の子コレクション保存・イベント発行タイミング・監査カラム・楽観ロック）。マイクロ ORM 採用の見積りにはこの設計コストを含めるべき
- **二方言運用の穴はマイグレーションではなく実行時 SQL に開く**。DbUp のプロバイダ別スクリプトで安心してはいけない。`NOW()` / `RETURNING` のような手癖の方言は規約 + 機械検出で塞ぐ
- **PlantUML のコンポーネント名に角括弧を含めてはならない**。`[名前[入れ子]]` は構文破壊。`component "..." as alias` 形式が安全
