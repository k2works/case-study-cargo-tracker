# 開発ジャーナル

日々のセッションで下した**判断の経緯**を残します。

コミットメッセージは「この変更が何を達成したか」を書きます。ジャーナルは **「なぜそうしたか、何を諦めたか、次回どう活かすか」** を書きます。両者は補完関係にあり、置き換えではありません。

**失敗の記録を省きません。** ジャーナルの価値の半分は「同じ罠に二度落ちない」ことにあります。
