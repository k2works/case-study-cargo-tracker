## 良かったと指摘された点

- `ConsigneeConfirmationRecordedEvent` が集約 → 投影 → クエリ → 画面まで全層で繋がっている（tracking 側の落ち方と好対照）
- `CargoDeliveredEvent` を `TransportStatusUpdatedEvent` と分けた判断、契約に載せない判断、`TrackingException` を集約内に置いた判断が、いずれも正典と一致
- 件数の非正規化を明細から数え直す形にした（累計にしていない）
- 境界値（`completedAt == now`）・再配送・スタブが引数を捨てないことの検査
- S43 が誤配と税関保留を選ばせず、その理由を画面に書いている
- S50 が引取のときだけ確認欄を出し、確認が無ければ送らせない
