## Problem（うまくいかなかったこと）

### P1. 「確認してから送る」が形だけになっていた

US25 §受入基準 3 は「確認した内容がそのまま送られる」です。実装は差分を表示したあとに `payload()` を組み立て直していたため、**確認したあとに入力を直すと、確認していない値が黙って送られました**。

運航変更の入力は、確認のあとにもう一桁直す操作が普通に起きます。受け入れテストは「確認 → 送信」の順で書いていたので全緑でした。**「途中で気が変わる」経路がテストにありませんでした。**

### P2. 期限切れの予約が、品名の誤りすら直せなかった

`updateSpecification` が到着期限に「今日以降」を無条件で求めていました。期限を過ぎた予約は**据え置きの再送でも断られます**。

画面のコメントには「受け付けたときの期限が今日より前でも、その予約は読めなければならない」と書いてあり、**コメントと実装が逆でした**。IT3 の T3（自分が書いた説明文ほど疑いにくい）の同型再現です。

### P3. 更新した航海に、偽の「重複」が積まれた

投影の `alreadyKnown()` は「行があれば読み直し」と判断していたため、**一度更新した航海に登録イベントが読み直されると、要確認一覧に「航海番号の重複」が積まれます**。運用の目に入るのは「重複」という誤った理由だけです。

`updated_at` を見て「更新された行への読み直し」を区別する形に直しました。P1〜P3 はいずれも**受け入れテストと単体テストが全緑の状態**で残っていました。

### P4. 計画の想定が、実際の経路の形と合わなかった

計画は「営業だけに絞る宣言を先に置く」としていましたが、`PUT /bookings/{id}` は `GET /bookings/{id}` と**同じ経路**です。経路だけの宣言では「読めるが直せない」を表せません。

`RoleAuthorization` を HTTP メソッド込みの宣言に拡張し、ADR-0006 に決定 6 として追補しました。**計画時点で経路の重なりを見ていれば分かる**ことでした。

### P5. 品質ゲートで初めて見つかった指摘が 10 件あった

JaCoCo の層別閾値割れ 3 件（`Cargo`・`AttentionItemId`・`VoyageSearchCriteria`）と、SonarQube の新規指摘 7 件です。いずれも**実際に検査していない分岐**か、**テストが `Instant.now()` を使っていた**ものでした。

ゲートは働いていますが、**ゲートに言われてから足したテスト**は「壊して赤」の順序を踏んでいません。

### P6. 一度だけ落ちて再現しないものが 2 件あった

`TZ=UTC ./gradlew build` が 1 度だけ落ち（`1 executed, 107 up-to-date` で、どのタスクかは特定できず）、クラスタ E2E が載せ直した直後に 2 回落ちました（その後 3 回連続で緑）。

Axon Server の起動待ちが、同じ Docker で kind と SonarQube が動いていると伸びることは分かっています。**心当たりはありますが確かめていません。** 「たまに落ちるテストは 2 回目で追う」に従い、次に見たら追います。

### P7. US32 §受入基準 4 が未達のまま完了扱いになった

「何を変えたか」を予約の履歴として見せる部分です。**記録はしていますが読み口がありません**（IT3 の T6「記録する先を足したら読み口も同じ変更で足す」に反しています）。航海側（US25）では最終更新を詳細に出したのに、予約側では出していません。

未達として計画に記録し、IT5 へ送りました。

### P8. 経路の検査が、相対で書かれた経路を 1 本も見ていなかった

クローズの再スキャンで見つかりました。`@RequestMapping("/api/v1/booking/bookings")` と `@PutMapping("/{bookingId}")` を繋いでいなかったため、**method 側に書かれた経路は「存在しないこと」**になっていました。Gateway のルートにも要求ロールの宣言にも無いまま緑になります。

サインは**未使用の private フィールド**でした。前置きを繋ぐために置いたものが、使われないまま残っていました。

Javadoc には「対象になりうるものを全部拾ってから書き方を見る」と書いてあります。**IT3 の T4 が守れていなかった形**で、方針だけが正しく拾い方が届いていません。繋いだ結果すべて載っていましたが、それは偶然です。
