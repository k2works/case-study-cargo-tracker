## 補足

- 手順書に書く版とコマンドは、**実際に実行して確認したものだけ**にします。想定を書くと、次に読んだ人がそこで詰まります
- 環境を変えたら手順書も同じ変更で直します。ずれた手順書は、書いていないより読者を迷わせます
