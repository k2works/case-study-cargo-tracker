## 実施方法について（正直に記録する）

**5 視点のうち、独立したレビューが返ってきたのは利用者代表 1 つだけである。**
これで **3 回連続**である（IT15 は 4 体、IT16 の計画時は 2 体が無応答）。

今回は [IT15 ふりかえり](../development/retrospective-15.md) Try 4 に従い、
**待ち時間の上限（1 時間）を先に決めてから起動した**。判断は速くなったが、
**上限を決めても、独立したレビューが得られない事実は変わらない。**

| 視点 | 実施者 | 結果 |
| :--- | :--- | :--- |
| 利用者代表 | 独立したレビュー | **高 5・中 5・低 4 件**。うち 1 件は実装者が入れた退行 |
| プログラマー | 自己レビュー（代替） | 判定の写し・空振りの検査を機械的に確認（`doesNotContain` 全 10 か所） |
| テスター | 自己レビュー（代替） | 足した検査を 1 つずつ壊して赤を確認 |
| アーキテクト | 自己レビュー（代替） | ADR-032 の決定 1〜7 に検査が対応しているかを表で確認 |
| テクニカルライター | 自己レビュー（代替） | 索引の欠落・画面との用語の食い違いを検出（下記） |

**自己レビューは独立したレビューより弱い。** その証拠に、利用者代表が挙げた高 5 件の
うち**自分で見つけられたのは 0 件**である。

## 指摘と対応

### 高（利用者代表・5 件）

| # | 指摘 | 対応 |
| :--- | :--- | :--- |
| 1 | **取り消した請求書が検索から消えた**（実装者が入れた退行）。US38 の絞り込みで `voided_at IS NULL` を一覧にも掛けた。赤伝こそ後から引かれる——「先月出し直した請求の元の番号は」「監査で取消理由を」。消すと詳細の URL を直接叩く以外に開けない | **対応**。合計からは外し、一覧には残す。**請求番号で名指しすれば引ける**ことをテストで固定 |
| 2 | **1 通開いて戻ると絞り込みが全部消える**。月次照合は「その月の 180 件を上から開く」作業で、1 通目で条件が消えると 180 回選び直す | **対応**。条件を URL に載せ、詳細リンクと戻り先も条件を持つ |
| 3 | **荷主が過去の知らせを読み直せない。マニュアルは「読める」と書いている**。出した時点で既読にする設計と組むと、回線が切れた・見落とした荷主はその知らせに二度と到達できない | **対応**。自社貨物の詳細に「お知らせ」欄を追加。**いつの知らせかも添える** |
| 4 | **マニュアル 15 章の「出るか」の表が TD-02 前のまま**。「夜間に回さないでください」も残る | **対応**。表を実態に更新し、**夜間の禁止は外れたが一晩の確認はまだ 1 度も行っていない**ことを明記 |
| 5 | **マニュアル 12 章の「できないこと」が同じ章の手順と矛盾** | **対応**。削除し、実際に残る制約（状態での絞り込みが無い）に置き換え |

### 中（利用者代表・5 件）

| # | 指摘 | 対応 |
| :--- | :--- | :--- |
| 6 | 一度に 20 件のポップアップが画面を覆う | **対応**。同時 4 件までにし、あふれた分は件数で伝える |
| 7 | 知らせに「いつの話か」が無い | **対応**。業務タイムゾーンで時刻を出す |
| 8 | 「過去の継続実行」から次の行動へ繋がっていない（種を紙に書き写させる） | **対応**。種を押すと継続実行の入力欄に入る |
| 9 | 日で絞ったのに「まだ実行していません。」と出る | **対応**。「〈日付〉に実行はありません。」とし、**日付の入力欄より後**に置く |
| 10 | 経理の一覧に**状態での絞り込み**が無い（「期限内だがまだ入金が無い」を月で見られない） | **IT17 へ**。新しい絞り込みの追加であり、入金消込がこの画面で完結する価値がある |

### 低（利用者代表・4 件）

| # | 指摘 | 対応 |
| :--- | :--- | :--- |
| 11 | 検索欄のラベルが目的でなく項目名 | **対応**（「精算書を探す（請求番号・荷主名・予約番号）」） |
| 12 | マニュアルの「15 秒ごとに」は荷主に不要（システムの都合） | **対応**（「数分以内に気づけます」） |
| 13 | 経理の権限で予約詳細が 403 にならないか | **確認済み・問題なし**。`ROLE_ACCOUNTANT` はルートの許可に入っている |
| 14 | 検索語の `%` `_` が未処理 | **IT17 へ**。前後の空白は `InvoiceSearchCriteria` が落としている。ワイルドカードは既存の一覧・検索が同じ書き方で揃っており、変えるなら全体を揃える |

### 自己レビューで見つけたもの

| 指摘 | 対応 |
| :--- | :--- |
