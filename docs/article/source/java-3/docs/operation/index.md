### 運用コマンド

| コマンド群 | 用途 | 定義 |
| :--- | :--- | :--- |
| `npx gulp dev:help` | アプリケーション開発（ビルド・テスト・kind 統合） | `ops/scripts/develop.js` |
| `npx gulp deploy:dev:help` | 開発環境（Heroku）へのデプロイ | `ops/scripts/deploy.js` |

環境への操作はここに定義したタスクを使い、使い捨てスクリプトを別途書かないでください。
