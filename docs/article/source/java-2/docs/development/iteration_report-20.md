## 課題と残作業

### 計画外に受けたもの

**真夜中に落ちるテスト 20 件**（2026-08-13 00:09 に品質ゲートで発覚）。

IT20 着手前のコミットでも同じ 11 件が落ちるため、**本 IT の変更が原因ではない**。テストが作業日時を `LocalDateTime.now(clock).minusHours(1)` で作っており、業務のタイムゾーンで 00:00〜00:59 に走らせると前日に落ちる。アプリは「作業日時が追跡番号の発行日より前です」と**正しく拒否**していた。

**同じ書き方が 6 か所**にあり、共有ヘルパへ寄せた。**落とす順序は見直していない** —— 品質ゲートの一部であり、これを落とすと「CI が緑である」と言えなくなる。所要 2h は余白（18h）で吸収した。

### 次イテレーションへの引き継ぎ

**育つ負債は本 IT の時点で 0 件である。** 返済枠の候補と判断が要ることは [ふりかえり](retrospective-20.md) の「次イテレーションへの引き継ぎ」に記載した。

とくに次の 2 件は**送り続けると固定化する**。

| # | 内容 | 状況 |
| :--- | :--- | :--- |
| S1 | `LocalDateTime.now(clock).minusHours` 直書きを禁じるソース走査検査 | 直書きは 0 件にしたが、**7 回目を止める仕組みが無い** |
| N1 | 負荷試験（`release_scope.md` は追跡 API に 1 本と定める） | **IT19・IT20 と 2 IT 連続で「名前で記録して次へ送る」** —— ADR-025 が返金・多通貨で踏んだ道と同じ |
