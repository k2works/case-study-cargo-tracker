## 特筆すべき指摘

**アーキテクトが ArchUnit の新ルールを独立に壊して確かめた。** 他 BC の集約を注入すると
ルール 4 と新ルールの両方が赤、他 BC の **ACL ポート**を注入すると**ルール 4 は緑のまま
新ルールだけが赤**になることを実測している。ADR-012 が「0 件であることを検査で守る」と
書いた意図どおりに機能していることの、実装者以外による確認である。

**利用者代表の指摘 3 件のうち 2 件が、プログラマ・テスターと同じ欠陥を別の入口から
指しており**（H1 は「緩和が消える」、H5 は「失敗が分かる仕組みがあると読める」）、
視点を分けることの効用がそのまま出た形になっている。

## 次イテレーションへの引き継ぎ

上表の「IT9 へ送る」を参照。とくに次の 3 件は性質が重い。

1. **ADR-012 の矢印の向きの混用（M1）** — 規律の実効性そのものに関わる

3. **Tracking が持つ写しに再同期手段が無い（architect の懸念 2）** — プロセス断で失われたイベントは `EventualConsistencySkips` にも現れない
