**Phase**: Phase 1 (Release 0.1 Internal Alpha) + Phase 2 一部前倒し

## ハイライト

国際貨物輸送管理システム (Haskell 版) の最初の内部レビュー用バイナリです。Phase 1 (IT1-IT2) で確立した基盤に加え、IT3 で本格的な経路設計フローと国際通関連携を追加しました。

* **見積から予約・経路選定の動線が SSR UI で通る**: 営業担当者は `/estimates/new` で見積を作成し、「この見積で予約する」リンクから貨物予約 → 経路候補表示まで一連のフローを完了できます
* **国際通関情報の予約紐付け**: HS コード (6-10 桁) と通関業者・申告ステータス (Pending/Cleared/Held/Rejected) を予約に紐付け、税関申告の追跡基盤を整えました
* **航海スケジュール検索 + 経路候補算出**: 経路設計者は `/voyages/search` で航海を検索し、`/bookings/:id/routes` で接続性・期限を満たす最大 5 件の経路候補 (rank 順、直行便優先) を確認できます
* **アーキテクチャ規約の固定化**: arch-check Phase 1 (Rule 4: BC 間直接参照) が ALLOWLIST 0 件で gate になり、ADR-0004 ShipperRef / ADR-0005 BookingError の段階移行を開始しました

### 横断機能

* **認証**: JWT (Bearer) + Cookie 両対応のログイン / ロール 8 種
* **ロール別ナビメニュー**: 未認証 / Sales / Router / MasterAdmin / Shipper / Consignee / Tracker / Handler / Accountant でメニュー出し分け (U-07 Phase 1)
* **htmx 動的フォーム**: CargoType 切替 / 荷主検索オートコンプリート / 航海更新差分
* **PRG パターン**: 全 POST が 303 → ?flash= or ?error= で再描画
* **楽観ロック**: cargo / voyage / invoice / estimate / shipper / customs_declaration 集約

## 既知の制約

* **Production 非対応**: APP_ENV=production 用の fail-fast は実装済だが、HTTPS / Secrets Manager 統合は未実施。本リリースは内部レビュー / デモ専用です
* **arch-check Phase 2 / Phase 3**: Rule 6 (Interfaces → Domain) と T-01〜T-03 (トランザクション境界) は IT4 以降で実装予定 (haskell-src-exts AST バイナリ起票済)
* **Handling Context 未実装**: `customs_declaration` テーブルは US27 用の最小カラム (booking_id / hs_code / broker_name / declaration_status) で先行作成。Handling Context (`handling_activity`) は IT4+ で追加
* **Playwright E2E 拡張**: US01 / US06 / US25 のハッピーパス追加は IT4 へ繰越 (U-08)
* **Handler 単位の認可 enforcement**: U-07 Phase 1 では UI レイヤのメニュー出し分けのみ。403 enforcement は Phase 2 で段階移行
* **経路候補のスタブ実装**: `/estimates/new` の RouteCandidate は固定 2 件のスタブ。実際の RouteFinder との統合は IT4+ で実施

## アップグレード手順 (内部)

### 1. リポジトリのチェックアウト

```bash
git clone https://github.com/k2works/case-study-cargo-tracker.git
cd case-study-cargo-tracker
git checkout v0.1.0-alpha   # タグが公開された後
```

### 2. 開発環境の起動

```bash
nix-shell ops/nix/shells/shell.nix
cd apps/cargo-tracker
docker compose up -d postgres
dbmate up
stack build
stack run cargo-tracker-exe
```

### 3. 動作確認

* http://localhost:8080/ ホーム
* http://localhost:8080/login (seed user: admin / sales / router / handler、全パスワード `password`)
* http://localhost:8080/estimates/new (Sales)
* http://localhost:8080/voyages/search (Router)
* http://localhost:8080/bookings/new (Sales)
