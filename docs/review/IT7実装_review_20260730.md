## クローズ内で対応した指摘（11 件）

1. **割引率の逆算による復元クラッシュ**（programmer H1・[[domain-state-no-rederivation]]）: `discount_rate` を数値カラムで永続化（migration 013）し、reconstruct は保存値をそのまま採用。整数丸めで 0.3 を超える逆算で CONFIRMED/OVERDUE 請求書が復元不能になる重大バグを解消。
2. **paidAt が復元で常に null**（programmer M4）: payment テーブルから paidAt を復元し、再 update での payment 二重生成を防止。
3. **ROLE_BILLING 認可の拒否テスト + billing 経路の fail-closed 回帰**（tester H1/H2）: 非 BILLING ロールで請求経路が 403、未認証で 302 /login になる回帰を追加。
4. **入金確認のドメイン状態チェックを gateway 呼び出し前へ**（programmer H2）: CONFIRMED/REFUNDED を先行チェックし二重確認の窓を閉じる。
5. **ダッシュボード OVERDUE 件数の過少表示**（architect M3・user M3）: sweep 未実行でも「発行日+30日 < now かつ PENDING、または OVERDUE」を動的判定する読みモデルへ変更。
6. **generate-invoice / mark-overdue のサービス単体テスト**（tester M6）: 分岐（DELIVERED 拒否・二重請求・調整・通知失敗握り・OVERDUE 初回のみ通知）を Fake でユニット固定。
7. **期限超過の境界値テスト**（tester M3・[[date-vs-timestamp-deadline]]）: dueDate 同時刻/+1ms/当日23:59 の 3 ケースを追加。
8. **金額計算の端数テスト**（tester M4）: 税10%に端数が出る組み合わせを追加し集約レベルの丸めを固定。
9. **精算書通知本文に支払方法・振込先案内**（user H1）: buildIssuedBody に固定案内文言を追加。
10. **未解決例外あり時の発行前注意喚起**（user M5）: 料金算出画面で未解決例外がある場合に調整要否の警告を表示。
11. **請求書詳細の荷主名表示 + 用語是正**（writer L7・user L7・writer H1）: 詳細を荷主名表示へ、ダッシュボードカード見出しを「支払期限超過の請求」にして「未払い」語の二重意味（PENDING vs OVERDUE）を解消。

## 次テイク/バッファ期間への引き継ぎ

- **非同期リスナー例外の非捕捉と AFTER_COMMIT 未強制**（architect H1/H2）: 同期 emit + async リスナーの拒否は発行側 try/catch で捕捉されない。リスナー内 catch で握る現状は機能するが、write と emit が別 autocommit で状態デシンクの余地。ADR-009 に「同期 emit / async リスナー例外は発行側で捕捉不可」を明記し、transaction/outbox の構造化を Release 1.0 後に判断。
- **BillingSnapshotAcl の 4 テーブル直読と契約テスト**（architect M4）: 過去最大の DB 結合（cargo/leg/shipper/exception・shipper PII 含む）。スキーマ変更で赤くなる契約テストの追加、将来の read-model/API 化。
- **距離係数の距離マスタ化**（architect M5）: transitDays 比例は遅延ほど高額になる逆インセンティブ。港間距離マスタまでの暫定であることをドメイン/ADR に明記。
- **PaymentGatewayPort の失敗モード**（architect M7）: スタブが常に入金済みを返すため未入金分岐の到達性が弱い。失敗モード + HTTP 契約テスト。
- **@Public のメソッド単位付与原則**（architect M6）: クラス単位 @Public（auth/health）は将来ルート追加時の暗黙公開リスク。ADR-011 に制約明記。
- **業務機能の拡充**（user M4/M6・tester M8）: 料金調整の承認・上限・根拠記録、部分入金/過入金、督促バッチ。
- **リスナー冪等性の楽観ロック**（architect L8）: マルチインスタンス化時の二重遷移防止。
- **ドキュメント同期**（writer M2/M3/M4/L5/L6）: バッジ色仕様・請求書 ID の残存・精算書/請求書の呼称統一・未請求バッジ記載を用語集で整理。
