## IT10 対応方針

### A1（認可深層強化、US30）に統合

- **H3 JWT 信頼境界**: PreAuthFilter を各 ms に追加して `X-Forwarded-Role` を Authentication に変換
- **H4 認可統合テスト**: `@WithMockUser` + slice テストで `@Profile("!heroku")` でも認可ロジックを検証
- **H10 ロール棚卸し運用**: ROLE_ACCOUNTANT 等の付与・棚卸し手順を `docs/design/operation.md` に追記
- **M1 SecurityConfig 共通化**: `shared-security` モジュール抽出（任意）

### A2（fallback UX、US31）に統合

- **M9 端数処理ルール**: 「残額しきい値（例: 100 円）以下は管理者承認で PAID 手動遷移」ストーリーを追加検討

### A3（staging E2E、US32）に統合

- **H5 統合テスト分割**: PaymentGatewayWebhookIntegrationTest を 3 メソッドに分割、await 5s に短縮
- **H6 境界値テスト**: HMAC tolerance 境界（299s/300s/301s）+ Clock 注入
- **H7 LocalStack IT 隔離**: `useJUnitPlatform { excludeTags("localstack-integration") }` を `:check` に
- **H8 業務例外パス**: `charge.refunded` / `charge.dispute.created` シナリオを staging で実機検証
- **H9 rotation アラート**: PagerDuty/Slack 通知の観測性ストーリーを追加

### A4（Flyway × enum、US33）に追加

- 既存スコープと整合、追加対応不要

### A5（Release 1.1 正式版、US34）の前提

- **M8 CHANGELOG 順序**: Release ライン経緯の明示
- **L5 README**: IT9 / Release 1.1 反映
- **L6 ADR ステータス**: 0020 / 0021 を「採用済み / 実装完了」に更新

### IT11+ 検討（持ち越し）

- H1 / H2 / M2 / M3 / M4 / M5 / M6 / M7 / L1-L4 / L7
- Invoice 集約の ES 決定性改善（PaymentRecordedEvent に paidSoFar を含める shared 契約変更）は影響範囲が広く慎重な ADR 起票が望ましい
