# 開発成果物レビュー（IT3 Routing BC）

- 実施日: 2026-07-09
- 対象コミット範囲: `11d57140..HEAD`（US24/US25/US07/US08 + 負債返済 H1/H2/H3/H4/T3・ナビ整合性・ログイン改善・Routing デモシード）

- 重点対象: US08 の RouteCandidateCalculator / VoyageRouteCandidateService（Codex 利用上限のためテックリード直接実装）

## 総合評価

IT3 の Routing BC は、ヘキサゴナル + 垂直スライス + DDD の既存パターンを高い忠実度で踏襲し、ADR-0006/0007 の設計判断がコード・ArchUnit・ドキュメントの三者で一貫した良質な実装である。集約境界とドメインサービスの純度は良好で、version 楽観ロックの実 DB 競合テストや AmbientTransaction ネストガードは堅実。一方、**US08 の RouteCandidateCalculator は境界値テストの穴（高）**、**費用計算の暫定性と単位/日本語化の UX（中）**、**経路候補からの次アクション導線の欠如（高）**、**domain-model のドキュメントドリフト再発（中）** が主要な指摘である。

## 懸念事項（要確認）

- **費用・所要日数が簡易算出（暫定係数）**（writer, user-rep）: 画面に「費用」として出ている以上「概算」ラベルを付けるか US08 後続で精緻化するか PM 判断。
- **経路設計者への依頼通知が未実装**（user-rep）: IT2 からの持ち越し。依頼一覧を能動的に見に行く前提。後続 IT で通知実体を拾う。
- **US07「港湾制約」が未実装**（user-rep）: 現在の絞り込みは貨物種別・時系列接続のみ。将来スコープ。
- **`IncludeRoutingDemo` 既定 true の本番流入リスク**（tester）: 本番セーフガード（`Enabled` false + 環境判定）はあるがテスト無し。
- **CSP 導入時のインライン script**（architect）: ログイン画面のデモ切替スクリプト。将来の非機能要件。
