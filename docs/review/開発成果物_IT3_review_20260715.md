# 開発成果物レビュー — IT3 Routing（US24/US25/US07/US08）

- レビュー日: 2026-07-15
- 対象: Routing Context 実装（ドメイン/アプリ/インフラ/Web/テスト）・ADR-0009・マイグレーション 0006
- 対象コミット範囲: `b45bc63a^..HEAD`（feat 6・docs 反映含む）
- レビュー方式: マルチパースペクティブ（xp-programmer / xp-tester / xp-architect / xp-technical-writer / xp-user-representative 並列）

## 総合評価

IT3 は中盤インサイドアウトの狙いどおり、Schedule 連結制約・Voyage 集約・RouteComputation をドメイン層に凝集させた良質な実装で、業務フロー（航海登録 → 経路設計依頼 → 候補算出）が受け入れテストで縦貫通している。一方、(1) **IT3 の成功基準「FsCheck で網羅」を満たす FsCheck プロパティが皆無**、(2) 経路探索アルゴリズムの境界（打ち切り・ループ回避・並び順・期限境界）と親子集約の原子性のテスト欠落、(3) **ArchUnit に Routing が未登録で BC 分離が構造検証されていない**、(4) post-commit イベント dispatch の再度の未結線、(5) US25 差分確認・US24 寄港地の受入未達、が要対応。多くはインサイドアウトの DoD（FsCheck・構造検証）と受入基準に直結する。

## 補足

- 「経路候補を予約に確定する」操作（US09-11）は IT4 スコープ。IT3 は算出・表示までで妥当（複数エージェントが確認）。
- FsCheck パッケージはテストプロジェクトに参照済み（`FsCheck.Xunit`）。H1/H2 の追加に技術的障壁はない。
