## 既知の懸念事項（ふりかえり Try 候補）

- **Testcontainers Kafka container race**: `./gradlew check` 連続実行で flaky。改善方向：Testcontainers Reusable + 一意 topic prefix（@DirtiesContext より望ましい）
- **`AggregateNotFoundException` の silent skip**: tracking 未初期化時に荷役イベントが先行すると永久にスキップされる。partition key 設計 + 順序不整合の再現テストを IT6 例外管理で追加
- **重複検知の 5 分窓固定値**: 業務によっては 30 秒〜10 分の幅。将来 properties 化を検討（YAGNI で今は問題なし）
- **トランザクション境界の統一方針 ADR 化**: `CargoDeliveredEventPublisher` の summary 参照 + publish の二段が非トランザクショナル。MEMORY の confirm publish/updateStatus と同じ問題が潜在
