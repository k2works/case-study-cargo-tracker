# 設計レビュー（CQRS / Event Sourcing 版）- 2026-09-02

## レビュー対象

`docs/design/cargo-tracker/` の設計 10 件と `docs/adr/cargo-tracker/` の ADR 2 件（いずれも `status: draft`）。

- architecture_backend.md / architecture_frontend.md / architecture_infrastructure.md
- domain-model.md / data-model.md / ui_design.md
- test_strategy.md / non_functional.md / operation.md / tech_stack.md
- ADR-0001 CQRS / Event Sourcing を Axon Framework 5 でマイクロサービスとして実装する
- ADR-0002 Event Store は Axon Server SE、Read Model は PostgreSQL + MyBatis

レビュアーは XP エージェント 5 名（プロダクトマネージャー、アーキテクト、インタラクションデザイナー、テスター、ユーザー代表）。各自が全文を読み、独立にフィードバックした。

## 総合評価

設計の内部整合と「Event Sourcing の代金を隠さない」姿勢は 5 名とも高く評価した。反映の遅れ（`202`）を画面規約・SLO・E2E に一貫して落としたこと、投影とトークンの同一トランザクションを決定・検査・運用の 3 か所で貫いたこと、要確認一覧（S70）で失敗を黙って捨てないことは、この種の設計で最も抜けやすい箇所を先回りしている。

一方で、**実装に着手すると赤になる、または現場で止まる欠陥が高優先度で 20 件**ある。技術面では、集約の登録 API が参照元の最終決定（take-4 ADR-0008）と食い違う、Axon Server の DCB 有効化設定が無い、投影がコマンドを送る設計が自らの ArchUnit ルールに違反する、crypto-shredding が投影の `NOT NULL` とリプレイに両立しない、Processing Group 名と契約イベントの名簿が文書間で割れている。業務面では、荷主・荷受人への通知手段が設計から欠落している、荷役作業員の使い方（航海番号起点・連続記録・現地時刻）が想定されていない、キャンセル承認後に追跡を閉じると陸揚げの荷役が記録できない、誤配の再設計で候補が 0 件になる。

判定は**条件付きで進めてよい**。高優先度 20 件のうち 17 件を修正し、2 件を次工程（開発戦略・リリース計画）に引き渡し、1 件（通知）はスコープ外と明記する。

### 評価サマリー

業務のことをよく分かって書かれた設計。この方針なら現場に出せる。ただしそのまま作ると現場で止まる箇所が 5 つ：通知が設計から消えている、荷役作業員の使い方が想定されていない、キャンセル承認後も貨物は船の上にあるのに追跡を閉じる、誤配の再設計で候補が 0 件、見積と請求は一致しないという事実に向き合っていない。「反映中」は営業・経理・経路設計では受け入れられる。荷役だけは条件付き。

### 良い点

- 「保存しました」と言わない
- 拒否は集約の判定であり画面の誤りではない
- 要確認一覧
- 通関済でない貨物の引取を拒否（ここだけ拒否は正しい）
- 通知していない予約は確定できない
- 期限は日付単位、当日着は間に合う
- 期限超過を列に持たない、当日は超過でない
- 公開追跡に例外の詳細・荷主名・金額を出さない

### 改善提案

- 【高】通知手段が設計に無い。`ShipperNotifiedEvent` に宛先と要約、S22 に通知履歴。作らないならそう明記
- 【高】荷役作業員の使い方：航海番号起点、記録後に同じフォームへ戻り送信済みが積み上がる、完了日時は港のローカル時刻（JST 併記）
- 【高】通関済直後の引取拒否：判定時点を出し再確認ボタン。S52 から「通関済で引取未記録」を辿る
- 【高】キャンセル承認後も陸揚げの荷降しが記録されるまで追跡を開けたまま。陸揚げ地は現在地または残りの寄港地から選ぶ。S23 の画面イメージ
- 【高】誤配の再設計で期限超過候補も超過日数つきで出す
- 【高】見積と請求は一致しない。差額と理由、調整の根拠の例外へリンク
- 【中】留置 3 日超は営業日で。留置日数を請求へ
- 【中】通関申告が輸入のみを想定していることを明記
- 【中】例外の緊急度は残日数で並べる
- 【中】一覧の既定条件を画面ごとに
- 【中】荷主が予約の進み具合を見られない
- 【中】荷役の誤記録を打ち消す操作
- 【中】S70 の担当ロールと 3 日以上未確認の強調
