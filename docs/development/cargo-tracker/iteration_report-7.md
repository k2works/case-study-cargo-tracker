## 技術的成果

- **`BookingReactionHandler`（Reaction Handler の 1 本目）** — 2 段の連鎖を `process_state` で追う。**Saga ではない**（ADR-0001 決定 6）。再試行 3 回・上限超過で `RevertTrackingNumberCommand` + `attention_item`
- **契約コマンドの 1 本目** `InitializeTrackingCommand` — ゴールデン JSON を赤から始めて固定。走査で名簿を導き、列挙型・識別子型を断る検査を新設
- **trackingms の最初の集約** `TrackingActivity` と投影 `tracking_summary` / `tracking_leg`
- **採番は投影側**（`TrackingNumberGenerator` ポート）。集約で MAX+1 しない
- **ADR-0010** — 決定 4 つ、それぞれに検査を対応
- **`architecture_backend.md` の「Saga パターン」節を書き換え** — ADR-0001 より古い記述で、そのまま実装するとコンパイルできない
