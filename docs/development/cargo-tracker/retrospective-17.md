## Keep

### 引き継ぎ 2 を「7 IT 目の先送り」にしなかった

S45・S46 は IT11 から 6 IT 連続で起票されず、IT17 の計画で初めて**行として**立てました。
着手して分かったのは、正典の「未実装」が「ルートだけが無い」ではなく
**読み口も荷主で絞る一覧も実装 0 件**だったことです。見積もりは 6h の一部ではなく単独で 5〜8h
でした。**落とした負債は育つ**——先送りするほど、次の IT で対象が増えます。

### 「実物を通す」ことでしか出ない欠陥が、また 3 件出た

層ごとの検査はすべて緑でした。クラスタで荷主としてログインして初めて、
`users.shipper_id` が**読まれるだけでどこからも書かれていない**（荷主向けの画面がすべて空）、
監査の `reason` が 30 文字で UUID が入らない（**識別子が列に収まらない形は 4 度目**）、
発行された追跡番号が画面に出ないことがある、が出ました。

### 除外の表を「未」ゼロにするまで追い切った

ADR-0020 決定 4 の表は IT16 で「未」を自覚して残したものです。IT17 の T0 で
`trackingms`・`handlingms`・`bookingms` へ印を運び、表を閉じました。
**レビューでさらに 3 つ（S42・S23・S52）が見つかりました**——表が「完成して見えていた」ことが、
この形のいちばん危ないところです。

## Problem

### 層が全部緑のまま、US36 §1 が一度も働いていなかった

乱数を集約の中に持ったため、稼働を読み直すたびに同じ位置から引き直していました。
集約・サービス・マッパー・画面のどのテストも自分の層では正しく、
**「毎回ちがうか」を見る検査だけがどこにも無い**状態でした。レビューで初めて出ました。

**「毎回ちがう」は層をまたぐ性質です。** だから誰のテストも書かなかった——これが根本です。

### 判別しない検査が 4 件あった（Try T3/T7 は 15/20 コミット）

- 停止の受け入れが `await(() -> size() == before)` で**1 回目のポーリングから真**
- `allMatch("RESOLVED"::equals)` が**空リストで真**
- クラスタ E2E が知らせのポップアップに**一度も触れていない**（US37 §2・§6 がどこでも未検査）
- 環境変数の一覧が手書きの名簿（**次に足したものが漏れる**）

Try T3/T7（書いた検査はその場で壊して赤を見る）は IT16 の 13/30 から 15/20 へ改善しましたが、
**残った 5 件のうち 4 件がそのまま判別しない検査になりました**。割合ではなく「1 件も残さない」で測るべきでした。

### マニュアルの「いま使える範囲」が 6 章ぶん古かった

ch.00 の担当と画面の表は 5 行のまま、ch.01 の範囲は「経路設計の通知まで」で止まり、
見積・請求・キャンセル・シミュレーション・荷主向けの章が表に載っていませんでした。
**章を足すたびに索引は直していたのに、「範囲」を書いた本文は誰も見に行かなかった**からです。

### 荷主の紐付けに画面が無いまま IT を終える

`POST /api/v1/auth/admin/users/{username}/shipper` は作りましたが、画面はありません。
**運用の担当者が API を直接叩く形**で、マニュアル ch.06 にその旨を書きました。
US37 の前提だったので実装は必要でしたが、入口としては未完成です。

## Try

| # | 改善 | 期待する効果 | いつ |
| :--- | :--- | :--- | :--- |
| T1 | **「層をまたぐ性質」を受入基準ごとに 1 度書き出す**（毎回ちがう・順序が保たれる・重複しない など）。書き出したものは、どの層にも属さないので**専用の検査を立てる** | US36 §1 のように、全層が緑のまま一度も働かない形を塞ぐ | IT18 の設計時 |
| T2 | **待ち条件を書いたら「1 回目のポーリングで真になるか」を声に出して確かめる**（Try T5 の言い換え）。真になるなら `during` で「続く」ことを見る | 停止・静止・不変を確かめる待ちは、ほぼすべてこの形で空振りする | 常時 |
| T3 | **`allMatch` / `noneMatch` / `allSatisfy` を書いたら、その直前に `isNotEmpty()` を置く** | 空集合で真になる述語は、確かめたい事象が起きていなくても緑になる | 常時 |
| T4 | **検査を壊して赤を見る（Try T3/T7 の 5 IT 目）を「割合」でなく「残数 0」で測る** | 15/20 でも、残った 5 件のうち 4 件が判別しない検査だった | 常時 |
| T5 | **UI の章を足したら、「いま使える範囲」を書いた本文（ch.00・ch.01）も同じ変更で開く** | 索引だけ直して本文が残る形を塞ぐ。マニュアルの索引と本文は別の場所にある | 常時 |
