## 技術的成果

### 新規の設計判断

**ADR-022: 読み取り側の「規則」は application 層に置き、「問い合わせ」は infrastructure に残す**

業務の言葉で説明できる判断があり、**かつ確かめるのに DB の起動が要る**ときだけ分ける。JOIN を詰め替えるだけの一覧は分けない。CQRS の読み取り側を MyBatis で書く既存方針に**例外を作らない**選択とした。
