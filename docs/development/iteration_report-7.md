## エグゼクティブサマリー

**本 IT で「作った人以外が初めて使う」段階に入った。** IT1〜IT6 で作った画面はすべて社内ロール
（営業・経路設計者・追跡管理者・荷役作業員・管理者）向けだった。US18 の公開追跡は
**認証を持たない相手に見せる最初の画面**であり、見せてよい情報の範囲がそのまま設計上の制約になった。

**IT6 で一本つながった線に、終点（引取）と、荷主が自分で見る入口（追跡照会）が付いた。**
E2E のクリティカルパスは「予約 → 経路 → 確定 → 追跡番号 → 受領 → 積込 → 荷降し → 引取 → 配送完了 → 追跡照会」
まで伸び、終盤の完了条件である 3 本（US13 / US15 / US18）を達成した。

**返済枠 5 件をすべて完済した。** IT2 から 6 IT 連続で「余力次第」にせず時間で確保する運用が守られている。

**レビューの高優先度 9 件はすべて IT 内で対応した。** 共通していたのは
「**宣言はしたが実装が無い**」形である（後述）。

### 設計判断

| # | 判断 | 理由 |
| :--- | :--- | :--- |
| 1 | **`CorporateShipper` サブタイプをやめ、`CorporateContract` 値オブジェクトにした** | 実装の `Shipper` は `final` かつ不変であり、継承すると「法人なのに契約が無い」「個人なのに契約がある」組み合わせを型で防げない。`domain-model.md` を修正 |
| 2 | **読み取った追跡番号を荷役作業自身の列として持つ** | 予約への参照ではなく「そのとき何を読み取ったか」という作業の事実。誤読しても誤った番号がそのまま残るほうが追跡できる。join にすると Handling の SQL が Booking のテーブルを読むことにもなる |
| 3 | **レートリミットは単一プロセス内に留める**（ADR-011） | 分散カウンタは基盤の判断が先。現状は上限が無限であり、N 倍は無限より小さい。**限界を記録しないなら入れないほうがまだよい** |
| 4 | **`/actuator/health` をレートリミットの対象外にする** | 過負荷時に liveness が 503 を返すと ECS が再起動ループに入る。**防御が障害を作る** |
| 5 | **公開画面と認証つき画面で同じ表示データを使う** | 見せる範囲を画面ごとに変えると、片方にだけ個人情報が混ざる形が生まれる |

### 検査が設計の誤りを 4 回捕まえた

| 検査 | 捕まえたもの | 直した形 |
| :--- | :--- | :--- |
| Checkstyle（パラメータ数） | 荷役に読み取った番号を足した | `HandledCargo` |
| Checkstyle（パラメータ数） | 引取確認を足した | `HandlingDetails` |
| Checkstyle（循環的複雑度） | `apply` の boolean が 3 個 | 種別名 1 つに変え、責務を分けた |
| ArchUnit（レイヤ依存） | アプリケーション層がインフラの Mapper を直接参照 | 出力ポート `PortNames` を抽出 |

**いずれも上限を緩めなかった。** IT6 で確立した「上限に当たったことを、概念を見直す合図として使う」がそのまま働いた。

### 高優先度 9 件に共通した形

**「宣言はしたが実装が無い」。** 画面のコメントが「予約の荷受人と違えば警告を出す」と宣言しながら
照合は場所しか見ていない、「担当者メモに理由を記入してください」と案内しながらメモ欄が無い、
計画に「作業日時の下限を設ける」と書いて実装しない、など。

**IT6 の P3（Javadoc の宣言と実装の食い違い）と同じ形が、場所を変えて再発した。**

### 前 IT の指摘が 2 件そのまま再発した

- **付録 B に当該 IT の症状が 1 件も無い**（IT6 の H8 と同じ）
- **マニュアルの項目表が実画面とずれている**（IT6 の H7 と同じ）

どちらも **IT6 の Try に入っていなかった指摘**である。ふりかえりで Try にしなかった指摘は、
次の IT で同じように出る。IT7 の Try T4・T5 に入れた。

### レビュー実施上の問題

`developing-review` は 5 つの XP 視点を並列に起動するが、**回答が返ったのは利用者代表のみ**だった。
残る 4 視点はフォールバック手順に従い本セッションで順次実施し、**高優先度 3 件を追加で見つけた**。
**「エージェントを起動した」ことと「レビューが行われた」ことは別である**（Try T6）。
