# ADR-0021: 貨物の知らせは押し出さず、読みに行く

## ステータス

採用（IT17 / US37）

## 文脈

荷主は「自社の貨物に新しいことが起きた」ことを知りたい（US37）。いまは追跡一覧（S40）や追跡詳細（S41）を開いて見比べるしかなく、**変わったことに気づく手段がない**。

知らせ方には 2 つの向きがある。

1. **押し出す**（サーバから WebSocket / SSE / Web Push で送る）
2. **読みに行く**（画面が一定間隔で問い合わせる）

本システムの越境はすべて Axon の契約イベント・コマンド・クエリで、ブラウザはメッセージ基盤を直接読めない。押し出す経路を作るなら、**Gateway と認証をもう 1 本通すことになる**（既存の HTTP の経路とは別に、接続を保ったまま荷主 ID で絞る仕組みが要る）。

**荷主・荷受人への送信基盤（メール等）は本リリースのスコープ外**である（`ui_design.md`「画面共通の規約」）。

## 決定

### 1. 押し出さない。画面が一定間隔で読みに行く

**荷主が求めているのは「数分以内に気づける」ことである。** 秒単位の即時性は業務の速さ（船は日単位で動く）に対して過剰で、そのために接続を保つ仕組みを 1 本増やす理由がない。

読みに行く間隔は **60 秒**とする。一覧のポーリング（30 秒）より長い——知らせは開いている画面と無関係に出るので、どの画面にいても走り続ける。

**この判断を文章のまま残さない**（US37 の設計判断）。間隔は画面の定数に置き、変えたときに 1 か所で済むようにする。

### 2. 既読はサーバが持つ

**ブラウザに持つと、荷主が端末を使い分けたとき同じ知らせが行く先々でもう一度出る**（US37 §受入基準 3）。事務所の PC で読んだ知らせが、帰りの電車のスマートフォンでまた出る——「読んだ」は人に属する事実であって、端末に属する事実ではない。

`trackingms` に `notice_read_position`（荷主 ID・最後に読んだ位置）を置く。荷主 ID は Gateway のヘッダから受ける（`TrackingController` と同じ形）。

**位置は戻さない。** 別の端末が先に読んでいればそちらが正で、古い画面の「ここまで読んだ」で巻き戻すと同じ知らせが再び出る（`GREATEST` で更新する）。

### 3. 「新着」は連番で決める

`tracking_event` の主キーは `event_id`（UUID）で、**順序を決める列が無かった**（着手前に実測）。索引も `(tracking_number, occurred_at)` だけである。

**時刻で既読を持つと、同じ時刻に入った知らせを取りこぼす。** `BIGSERIAL` の連番を足す。追記は `ON CONFLICT (event_id) DO NOTHING` なので、**リプレイでも既存行の連番は変わらない**（実測）。

## 代替案

**(a) WebSocket / SSE で押し出す。** Gateway と認証をもう 1 本通すことになる。得られるのは秒単位の即時性で、船は日単位で動く——**確かめたい業務の速さに対して過剰**である。接続が切れたときの取りこぼしを埋めるために、結局「読みに行く」経路も要る。

**(b) Web Push（ブラウザを閉じていても届く）。** 送信基盤がスコープ外である。加えて、届け先の登録と失効の管理が要る——**荷主の連絡先を 1 つ増やす**ことになり、US37 が求めていない責任を背負う。

**(c) 既読をブラウザに持つ。** サーバの表を 1 つ減らせるが、端末を使い分ける荷主に同じ知らせが繰り返し出る。**US37 §受入基準 3 がまさにこれを断っている。**

## 結果

**良い面.** 経路が 1 本増えない。知らせの読み口は他の読み口とまったく同じ形（Gateway → REST → 読み取りモデル）なので、認可も絞り込みも同じ検査で守れる。

**悪い面.** **気づくまでに最大 60 秒かかる。** 荷主が画面を開いていなければ、当然ながら気づかない——「開いているあいだの気づき」であって、通知ではない。ここは US37 の範囲であり、送信基盤が入るときに見直す。

**残っている窓.** 荷主が複数の画面（タブ）を開いていると、どのタブが先に「閉じる」を押すかで、他のタブに出ている知らせが既読になる。位置はサーバが持つので**同じ知らせが二度出ることはない**が、読まないまま消えることはありうる。知らせの中身は追跡詳細（S41）と履歴にも残るので、消えても辿れなくなるわけではない。
