# ADR 0004: 法人荷主の割引率上限を 30% とする

DiscountRate の値域をドメイン・DB の両方で 0〜30% に統一する。

日付: 2026-07-11

## ステータス

2026-07-11 承認されました（暫定。プロダクトオーナーの業務確認により変更されうる）

## コンテキスト

法人荷主（CORPORATE）の割引率上限が、ドメインモデル（DiscountRate 値オブジェクト: 0.0000〜0.3000、最大 30%）とデータモデル（shipper テーブルのコメント: 最大 15%）で食い違っていた（設計レビュー 2026-07-11 の重要度「高」指摘 #5）。ドメインで通った値が DB の制約で弾かれる（またはその逆の）不具合につながるため、ビジネスルールとして一本化が必要である。

## 決定

1. 割引率の上限は **30%（値域 0.0000〜0.3000）** とする。ドメインモデルの複数箇所（ビジネスルール・値オブジェクト定義・割引ポリシー）が一貫して 30% を採用しており、こちらを正とする。
2. DB は `shipper.discount_rate NUMERIC(5,4)` に `CHECK (discount_rate BETWEEN 0.0000 AND 0.3000)` を付与し、ドメインのバリデーションと同一の値域を強制する。
3. 本判断は設計整合のための暫定決定であり、プロダクトオーナーによる業務確認で上限が変わる場合は、domain-model.md・data-model.md・本 ADR を同時に改訂する。

## 影響

- DiscountRate 値オブジェクトのバリデーションと DB CHECK 制約が二重の防御線として同じ値域を守る。
- 上限変更時はマイグレーション（CHECK 制約の付け替え）が必要になる。

## コンプライアンス

- DiscountRate の境界値テスト（0%、30%、30.01%）で値域を検証する。
- マイグレーションの CHECK 制約とドメインの定数が一致することを統合テストで確認する。
