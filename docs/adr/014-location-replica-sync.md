# ADR-014: 地点マスタの複製は同一の種データファイルを配り、内容の一致をテストで検査する

`location` テーブルを持つ全サービスに同一内容の種データマイグレーションを配置し、その一致を検査するテストを置く。実行時のイベント同期は行わない。

日付: 2026-08-20

## ステータス

承認済み

## コンテキスト

[ADR-010](010-location-master-shape.md) は地点マスタの**形**（サロゲート PK・`unlocode` の UNIQUE・`time_zone` の NOT NULL）と**正の所在**（bookingms）を決めたが、**複製の同期方法は「routingms が地点を使い始める IT3 で決める」として先送り**した。IT3 で routingms が航海スケジュールの寄港地に地点を使うため、ここで決める。

Database per Service（[ADR-001](001-microservices-architecture.md)）のもとでは、サービス間で `location` テーブルを共有できない。よって複製が要る。決めるべきは 2 点である。

**どう配るか**: 地点は参照マスタであり、変更頻度が極めて低い（港湾の統廃合・改称は年単位）。一方で参照側（`cargo.spec_origin_unlocode`・`carrier_movement.departure_location_unlocode`）は外部キー制約を張るため、複製に無い地点は業務が受け付けられない。

**ずれたらどう気づくか**: 複製は「同じ内容を人が 2 箇所に書く」形になるため、必ずずれる。ずれた側のサービスだけが、ある地点を扱えなくなる。しかもその症状は「その地点を使う予約・航海を登録したときだけ」出る。テストデータがずれた地点を踏んでいなければ、CI は緑のまま本番で落ちる。

## 決定

1. **正は bookingms が持つ**（ADR-010 の決定 3 を維持）。地点の追加・改称は bookingms のマイグレーションを起点とする
2. **配り方は「同一内容の種データマイグレーションを各サービスに置く」**。地点を使うサービスは、bookingms と**同じ `INSERT INTO location ...` を持つマイグレーション**を自サービスに追加する。テーブルの形も同じにする（`country_code` / `time_zone` を含め NOT NULL）
3. **実行時のイベント同期は行わない。** 地点の追加はマイグレーションで配る
4. **ずれの検出は、名簿ではなく実体から行う。** 「`location` テーブルを作っているサービス」を全サービスのマイグレーションから機械的に検出し、**検出された全サービスで種データが正と一致すること**を検査する。どのサービスを検査するかを一覧（名簿）で持つと、載せ忘れたサービスほど無検査になる（名簿方式の検査は「載っていないもの」を素通りさせる）

### 代替案

- **`location` を専用サービスに切り出す**: ADR-010 で退けた通り、参照系マスタのために可用性の結合を増やす価値が無い
- **起動時に bookingms の API から取得して自サービスへ流し込む**: 起動順の依存ができ、bookingms が落ちていると他サービスが起動できない。参照マスタの都合で可用性を落とすことになる
- **ドメインイベントで配る（`LocationRegisteredEvent`）**: 年単位の変更のために常時の購読経路を維持することになる。地点が増えるのは運用作業であり、マイグレーションという既存の配り口で足りる
- **一致検査を置かず運用の注意で守る**: 守られない。ずれても症状が出るのは「その地点を使ったときだけ」であり、気づくのは本番になる

## 影響

### ポジティブ

- サービス間の実行時依存が増えない。各サービスは自 DB だけで起動できる
- ずれが CI で落ちる。しかも検査対象は実体（マイグレーションの中身）から導くため、サービスを増やしても登録を忘れられない

### ネガティブ

- 地点を 1 つ追加するのに、地点を使う全サービスへマイグレーションを追加することになる。頻度が上がるなら本 ADR を見直す
- 各サービスに同じ INSERT が並ぶ。重複だが、意図した重複である（複製そのものが決定である）

## コンプライアンス

- 種データの一致検査（`LocationSeedReplicaTest`）を shared に置き、全サービスのビルドで走らせる
- 検査は**破って赤になること**を確認してから採用する（1 行だけ違う複製で赤になること・`location` を作るサービスが 1 つも検出できなければ赤になること）
