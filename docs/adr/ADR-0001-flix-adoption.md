# ADR-0001: Flix の採用とバージョン固定方針

実装言語に Flix（JVM 上の関数型言語）を採用し、0.x 系であることに起因するリスクをバージョン固定と定期評価で管理する。

日付: 2026-08-03

## ステータス

2026-08-03 承認

## コンテキスト

本プロジェクトは DDD・XP・TDD のケーススタディであり、同一の題材（国際貨物輸送管理システム）を複数の言語で実装する試みの 1 つである。本 take では Flix を採用する。

Flix には他の JVM 言語にない次の特徴がある。

- **代数的効果とハンドラ**: ヘキサゴナルアーキテクチャの出力ポートを言語機能として表現でき、DI コンテナもモックライブラリも不要になる
- **代数的データ型とパターンマッチの網羅性検査**: DDD の値オブジェクト・状態遷移を型で表現し、状態追加時の考慮漏れをコンパイラが検出する
- **Datalog 制約解決**: 経路の到達可能性判定を宣言的に記述できる

一方、次の制約がある。

- **バージョンが 0.x 系**（本 ADR 時点で 0.75.1）であり、マイナーバージョン間で構文・標準ライブラリに破壊的変更が入りうる
- **エコシステムが存在しない**: Web フレームワーク・ORM・モックライブラリ・カバレッジツール・アーキテクチャ検査ツールのいずれも存在しない
- **配布形態が単一 JAR**: パッケージマネージャから導入できず、`flix.jar` を直接取得する必要がある

エコシステム欠落への対処は [ADR-0002](ADR-0002-self-built-web-and-security.md) で扱う。本 ADR は言語採用そのものとバージョン管理方針を対象とする。

## 決定

### 1. 実装言語として Flix 0.75.1 を採用する

学習目的のケーススタディであり、「代数的効果でヘキサゴナルアーキテクチャを表現できるか」という検証自体に価値がある。本方針は環境構築時に実機で確認済みである（効果宣言・ハンドラ適用・Java 相互運用による JDBC 接続が動作することを `src/Bootstrap.flix` のスモークテストで確認）。

### 2. バージョンを固定する

- `apps/cargo-tracker/flix.toml` の `flix` フィールドでコンパイラバージョンを固定する
- `flix.jar` は `ops/tools/flix/flix.jar` に配置し、Git 管理外とする（取得は `npm run dev:setup`）
- 取得バージョンは `.env` の `FLIX_VERSION` で制御し、既定値を `.env.example` に記載する

### 3. アップグレードは独立したコミットで行う

- **四半期ごと**に最新版で `flix build && flix test` を検証する
- 通った場合のみアップグレードする。アップグレードは他の変更と混ぜず、独立したコミットとする
- 破壊的変更で修正が必要になった場合は、修正内容を本 ADR の「備考」に追記する
- アップグレードを見送った場合も、見送った事実と理由を記録する

### 4. 撤退可能性を維持する

Flix が実用に耐えないと判断した場合に備え、以下を維持する。

- ドメイン層は効果を要求しない純粋関数として書き、Java への移植時に構造をそのまま写せる状態を保つ
- Java 相互運用はインフラ層に閉じる（`arch-lint` 規約 2 で機械検査する）
- **撤退の判断時期**: IT1 完了時点で「効果の伝播によるシグネチャ肥大化」を実測し、破綻の兆候があれば IT2 で設計を見直す

## 影響

### 正の影響

- 出力ポートを効果として表現でき、DI コンテナ・モックライブラリへの依存がなくなる
- 状態遷移の考慮漏れをコンパイラが検出する
- テストダブルが言語機能で得られ、テストの記述コストが下がる

### 負の影響

- **エコシステム欠落分をすべて自作する必要がある**（リリース計画で技術ストーリー 44 SP・全体の 30% を計上）
- 破壊的変更でビルドが通らなくなるリスクを恒常的に負う
- 開発者の学習コストが高い（代数的効果・Datalog）
- カバレッジ計測ができず、品質ゲートを代替統制で組む必要がある

### 実装上の制約（環境構築時に判明した事項）

| 事項 | 内容 |
| :--- | :--- |
| テスト関数 | `Unit \ Assert` を返す（`Bool` ではない） |
| ハンドラ適用 | `run f() with handler X { def op(args, k) = k(...) }`。継続 `k` を最後の引数に受け取る |
| Maven 依存 | `[mvn-dependencies]` に `"groupId:artifactId" = "version"` 形式で宣言する |
| JDBC ドライバ | ServiceLoader による自動登録が機能しない。`Class.forName` による明示登録が必要 |
| 配布用 JAR | `build-jar` は Maven 依存を同梱しない。`build-fatjar` を使う |

## コンプライアンス

- `flix.toml` の `flix` フィールドと `.env.example` の `FLIX_VERSION` が一致していること
- アップグレード時は独立コミットであること（コミット履歴で確認）
- IT1 完了時のふりかえりに「効果数・シグネチャ行数」の実測値が記載されていること
- `arch-lint` 規約 2（`domain/**` が `java.**` を参照しない）に違反がないこと
